# sandbox/ — Exploration & Analysis Tools

Non-production scripts for ROM analysis, opcode exploration, and data extraction. Not part of the extension build.

## Directories

| Directory | Description |
|---|---|
| `opcodes/` | Opcode analysis and reporting scripts |
| `boundaries/` | Boundary condition test scripts |
| `corpus/` | Script corpus analysis scripts |

These are run manually for research purposes and are not included in `npm test`.
