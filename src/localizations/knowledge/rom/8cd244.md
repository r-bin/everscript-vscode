The only script wait whose length the engine decides: a walk finishing, a text box closing, the
camera coming to rest. When nothing is pending it is a plain one-tick yield. The simulation
treats each one as an event at an unknown tick (at least one tick later) and records any order
it has to assume (`src/simulation/time.ts`).
