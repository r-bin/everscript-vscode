The SNES cartridge header the console and every emulator read: 21 bytes of title, then map
mode, cartridge type, ROM and RAM size codes, destination (region), developer id, version and
the checksum pair. Under HiROM it is file offset `0xFFC0`; the ExHiROM build has its copy at
file `0x40FFC0` (`docs/exhirom/port.md`).

Secret of Evermore (U): title `SECRET OF EVERMORE`, map mode `$31` (FastROM HiROM),
destination `$01` (North America).

The emulator uses title + destination to decide whether a ROM is Evermore or built on it
(`detectEvermore`, `src/emulator/webview/rom-game.js`): only then does it show the overlays,
the pause menu's OBJECTS / LOOT / CHEATS, TRACE / STACK and the script hook. The other
regions share the title but not the destination, and their addresses differ. The CDL export's
known regions check the title only (`src/emulator/cdl/known-regions.js`).
