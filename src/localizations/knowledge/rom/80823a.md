Vectors always point into bank `$00`, so the first 17 bytes of the NMI handler execute at
`$00:823A`, the slow mirror of the same bytes as `$80:823A`. Its body (VRAM/CGRAM queue
uploads, PPU register copies, `INC $0100`) is described in the WRAM entries that link here.

Why it matters for layout ports: under ExHiROM `$00:8000+` is a different part of the ROM
(file `0x408000+`), under SA-1 it is LoROM-style. Either way the vector table and a stub at
this address have to be provided by the port; the handler itself can stay where it is.
This is the only mirror-executed code found so far (title/intro only).
