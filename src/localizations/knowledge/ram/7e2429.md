Holds the 16-bit script ID of the currently active step-on trigger. Set by `$8FACB1`
when the player walks into a step-on trigger bounding box on a collision bit-14 (`0x4000`)
metatile. Holds `$FFFF` when the player is not standing on any step-on trigger.
Re-triggering is suppressed while `$7E2429` matches the trigger script ID until the player
leaves bit-14 cells and `$8FB083` resets it to `$FFFF`.
