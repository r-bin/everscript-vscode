# resources/tags/ — hand-authored tags

`tags.json` is the hand-written half of `soe://tags/` (the other half is
generated by `../tag-generate.js`). Format and rules:
[docs/soe-tags-spec.md §5](../../../docs/soe-tags-spec.md).

- Keys are dotted tag ids; `sub` nests child tags (`boy.sub.hp` = `boy.hp`).
- `parents` is a list (multiple inheritance). Parents define which sub-tags
  exist; children supply links.
- Links are precompiled. The plugin never reads `.evs` files; `source` only
  records how an address was worked out (e.g. `_BOY + ATTRIBUTE.HP (0x2a)`).
- External references (the wiki, Data Crystals) go in `claims`, which stay
  `unverified`.
- An entry adds to a generated tag of the same id and never replaces it.

`tests/memory/soe-tags.test.js` checks every boy/dog link against the enum
base + offset, and `soe://tags/check.json` reports load errors and broken links.
