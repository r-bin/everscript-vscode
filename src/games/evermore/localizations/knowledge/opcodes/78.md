Entity expression, animation word, mode expression. A non-player entity with 0 HP is skipped when `+$10` bit `$0008` is set or `$23D9` is clear; the skip path clears `$23D9`. Otherwise the handler sets `+$2E` = `$0400`, changes `+$10` to `(old | $0040) & $DFFE`, and clears `+$0300` at `+$12`. The even mode values 0, 2, 4, 6, and 8 select targets in the six-word table at `$8C:E100`: mode 0 adds no further state change; 2 sets `+$12` bit `$0200`; 4 sets `+$12` bit `$0100`; 6 clears words at `+$01` and `+$03`; 8 sets `+$10` bit `$0001`. These paths start the selected animation through `$90:8124`. Mode 10 selects a separate path at `$8C:E17B`, fetches another word from the script, and runs opaque helpers; it does not visibly call `$90:8124`. Its effect is unresolved. Word bit 15 clear: the animation id comes from `$C4:3C92 + word`; set: from `$8E:0032 + entity[+$60] + (word & $7FFF)`. See [the control-flow reconstruction](../../../../../../docs/disassembly/script-vm/animate.md).

## Why it exists

Every gesture in cutscenes.

## Notes

Odd modes read misaligned words from the dispatch table; values above 10 read beyond its six entries. Their behavior is not reconstructed.
