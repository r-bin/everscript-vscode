Operand = bit number in the save area at `$2258` (byte = n >> 3, mask from `$80:A87F`); expression not 0 sets the bit, 0 clears it (mask from `$80:A887`).

## Why it exists

Story flags: chests opened, bosses beaten, dialogue progress. They persist in the save file.
