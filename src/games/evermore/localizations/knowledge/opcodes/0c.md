Operand = bit number in the save area at `$2258` (byte = n >> 3, bit = n & 7). Expression not 0 sets the bit (OR with the mask table `$80:A87F`), 0 clears it (AND with `$80:A887`).

## Why it exists

Story flags: chests opened, bosses beaten, dialogue progress. They persist in the save file.
