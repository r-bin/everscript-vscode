The handler holds NMI palette uploads via `$7E:0F3C`, evaluates seven expressions, applies three offsets to BGR555 channel fields in a counted loop, uploads the staging range through `$80:85FA`, releases the hold, and returns with carry set. The fourth and fifth operand roles and DP `$18` remain unknown. `$90:D34C` is called in the loop but only reads DP `$14` and returns; it does not perform the palette recomputation.

The compiler-facing Everscript command is `color_filter()`; the handler's unresolved operand roles are intentionally left unnamed.
