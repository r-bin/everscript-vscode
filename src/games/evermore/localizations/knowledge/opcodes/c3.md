The dispatcher has no range check: the word for an opcode from `0xC3` up is read from `$8C:EA43 + 2 * (op - 0xC3)`, the code of the expression evaluator. The "handler" is wherever those code bytes point in bank `$8C` (the VFS page names it): low WRAM for words below `$2000`, hardware registers or open bus for `$2000`-`$7FFF`, and the middle of some bank `$8C` routine above. None of them is a handler.

## Why it exists

It does not: the opcode space simply ends at `0xC2`.

## Notes

Cannot work: running one crashes or corrupts the game. Not used by the original scripts.
