Allocates a free slot (`$8C:CF18`, slots from `$28FC`), starts the script at the packed 24-bit pointer as its own thread (`$8C:CE86` adds it to the run list) and continues in the same turn. The new thread inherits the bound entity (`+$0D`, whose reference count `+$3E` goes up by one).

## Why it exists

Cutscenes run several actors at once: each one gets its own thread.
