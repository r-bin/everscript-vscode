Allocates a free slot (`$8C:CF18`), starts the script at the packed 24-bit pointer as its own thread and continues in the same turn. The new thread inherits the bound entity (`+$0D`, reference count `+$3E` + 1).

## Why it exists

Cutscenes run several actors at once: each one gets its own thread.
