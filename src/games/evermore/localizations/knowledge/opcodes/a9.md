Entity and an even selector into `$8C:E6F8`: `$00`-`$0E` set the facing (`+$22` = selector); `$10`-`$36` set or clear one flag: `$10/$12` `+$10` bit `$4000` (set also clears pending damage), `$14/$16` `+$10` bit 2, `$18/$1A` `+$12` `$1000`, `$1C/$1E` `+$12` `$4000`, `$20/$22` `+$10` `$400`, `$24/$26` `+$10` `$80`, `$28/$2A` `+$12` `$C000`, `$2C/$2E` `+$14` `$20`, `$30/$32` `+$14` `$40`, `$34/$36` `+$14` `$800`.

## Why it exists

One opcode for many on/off switches.

## Notes

Selectors `$38` and up jump into code bytes: garbage.
