The one wait whose length the engine decides. The expression is an entity address (>= `$2000`): wait until its current action ends (thread state 6, via the move record or `+$88`). Or a small value: `$0100 + n` waits for text box n to close (state 10, n < `$0FAE`), 1 for the step-on trigger script (state 8, `$2429`), 2 for the camera to come to rest (state 12, DP `$BF`/`$C1`). When nothing is pending it is a plain one-frame yield. Yields.
