One byte of bits: `$08` the thread's bound entity, `$01` Boy, `$02` Dog; each selected one is frozen (`$8F:CD78`). `0xBC`, `0xBE`, `0xC0` jump into this handler with the mask preset.

## Why it exists

One instruction for any combination of actors.

## Notes

Original scripts only use mask `$08`.
