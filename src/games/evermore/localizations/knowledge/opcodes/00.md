Ends the running script and returns with carry clear. The slot state `+$03` is cleared and the bound entity's reference count (`+$3E`) drops by one. A called script returns to its caller: the caller slot goes back into the run list at `$2F28`. A thread's first script ends the thread: the run list is compacted, the active-thread count DP `$86` drops by 2 and the slot is free.

## Why it exists

Every script needs a terminator; scripts are byte streams with no length field.

## Notes

The most common opcode after the jumps and writes. `0x00` is also the expression terminator byte, which is why scripts read so often as `... 00`.
