Ends the running script. A called script returns to its caller (the caller slot goes back into the run list at `$2F28`); a thread's first script ends the thread and frees the slot. The bound entity's reference count (`+$3E`) drops by one.

## Why it exists

Every script needs a terminator; scripts are byte streams with no length field.

## Notes

The most common opcode after the jumps and writes. `0x00` is also the expression terminator byte, which is why scripts read so often as `... 00`.
