Expression = entity (or a small index 1..n, see below); word = event mask to `+$68`, word = trigger id to `+$66`. Mask bits: `$0040` talk, `$0100` hit, `$0200` death, `$0400` run it now (`$8C:CE4D` starts it as a thread with the reason in the slot's `+$09`). An index n < `$2000` instead writes room-level hooks `$0EA2[n-1]` / `$0EAC[n-1]` (`$FFFF` when the first word is 0).

## Why it exists

Bosses and enemies with death or hit scripts; loot scripts.
