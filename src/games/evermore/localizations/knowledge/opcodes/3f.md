Expression = an entity, or a small index n (< `$2000`). Entity: the first word is its event mask (`+$68`), the second the event script's trigger id (`+$66`). Mask bits: `$0040` run on talk (`$8F:AC0E`), `$0100` when hit (`$8F:C213`), `$0200` on death (`$90:83D3`, one-shot), `$0400` run now: `$8C:CE4D` starts the script as a thread at once, with the reason in the new slot's `+$09`. Index n: the two words go to room hooks `$0EA2 + 2(n-1)` / `$0EAC + 2(n-1)`; when the first is 0 the second becomes `$FFFF`. Hook 1 is the drop hook: a dying enemy that drops loot copies it into its own `+$68`/`+$66` (`$90:857B`), so the drop runs that script (vanilla: `attach_script(1, B, LOOT_DUST_REWARD)`, 47 times). Hooks 2-4 (mask `$0001`, 34 uses) handle room hooks. Hook 5 (`$0EB4`) is the Wings hook used for dungeon escape item scripts (`attach_script(WINGS_HOOK, ROOM_HOOK, BBM_WINGS)`). Both words are always consumed.

## Why it exists

Bosses and enemies with death or hit scripts; loot scripts.
