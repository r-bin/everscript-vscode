8-slot array of active physical and magical projectiles in flight (bazooka shells, spears, alchemy projectile particles, enemy spit/spores).

- **Slot count**: 8 slots
- **Stride**: 44 bytes (`0x2C`)
- **Total buffer size**: 352 bytes (`$7E:6387`–`$7E:64E6`)

### Struct Layout
| Offset | Type | Description |
|---|---|---|
| `+$06` | Word | Sprite ROM address offset |
| `+$08` | Byte | Sprite ROM bank (`$C0`..`$DF`) |
| `+$0C` | Word | Palette slot offset index |
| `+$10` | Word | Active status flag (non-zero when slot is active) |
| `+$14` | Word | Subpixel X position (world position = raw / 16) |
| `+$16` | Word | Subpixel Y position (world position = raw / 16) |
| `+$18` | Word | Subpixel Z elevation height (height = raw / 16) |
| `+$1E` | Word | Lifetime countdown timer (ticks before despawning or exploding) |
| `+$26` | Word | Projectile update behaviour code routine pointer |
| `+$28` | Word | Collision damage / impact power rating |
