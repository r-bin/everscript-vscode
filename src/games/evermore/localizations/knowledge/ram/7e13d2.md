32-byte array storing the execution rate and step direction for 32 dynamic palette channels:
- Value 0: channel is inactive/disabled.
- Positive (bit 7 clear): forward color interpolation (step A advances, step B diminishes).
- Negative (bit 7 set / `BMI` taken): reverse color interpolation (step B advances, step A diminishes); inverted via `EOR #$FF; DEC` to yield the absolute countdown reload duration.
