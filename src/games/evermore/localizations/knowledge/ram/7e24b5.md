Terminal downward vertical velocity threshold (subpixels per frame, fixed-point 12.4).
Set by trigger scripts prior to calling `$94:AC56` (typically 0x22 = 34 subpixels/frame). The gravity simulation loop checks whether current downward velocity `TRAJECTORY_VY` has reached `TRAJECTORY_MAX_VY`; once met or exceeded, the fall concludes. When within 16 subpixels (`0x10`) of this terminal speed, the routine triggers `fade_out()`.

This is a transient call argument with zero persistence benefit; it belongs in `<0x2834>` (`temp[]`).
