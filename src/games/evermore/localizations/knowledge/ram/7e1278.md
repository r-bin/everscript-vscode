One word per sprite palette, at byte offset `2·n` for sprite palette `n`. It holds the 16-bit
palette address the slot carries, exactly the value of a character record's `+0x09`. 0 means free.
Two characters with the same palette address share one slot.

In the table hack an address below `$8000` names a new palette in bank `$FA`.
