Head write offset into the partial CGRAM DMA queue (`$7E:1292`..`$7E:1371`).

When game routines need to stream color palettes during active gameplay without stalling the CPU for a full 512-byte transfer, `func_C085FA` writes a 7-byte request descriptor:
- `+0x00`: 16-bit ROM source address offset
- `+0x02`: 8-bit ROM source bank
- `+0x03`: 16-bit CGRAM target destination word/index
- `+0x05`: 16-bit transfer byte count

Advances by 7 bytes per entry and wraps modulo 224 (`0x00E0` bytes = 32 slots).
