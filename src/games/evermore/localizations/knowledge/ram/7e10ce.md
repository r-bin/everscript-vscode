160-byte continuous array (`$7E:10CE`..`$7E:116D`) holding the current runtime state index for up to 160 interactive objects placed on the active map.
Indexed as `$7E:10CE + objIndex`.
Room scripts and player interactions modify these bytes (e.g. chests opened, doors unlocked, switches toggled, destructibles smashed) which determines which sprite frame or metatile graphic to render.
