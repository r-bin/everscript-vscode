256-byte array containing 8 32-byte (`0x20`) channel descriptors managing multi-frame dynamic sprite animation sequences (e.g. companion dog breed transformations, NPC motion, spell projectiles):
- **Stride**: `$20` (32 bytes per channel descriptor).
  - `+$00`: Sprite CHR pattern / tile offset
  - `+$02`: VRAM base destination address
  - `+$04`: ROM source bank
  - `+$06`: Frame duration / hold ticks
  - `+$08`..`+$1A`: Frame pointers, palette mask, priority, bounding box
  - `+$1C`: Channel active flag (`$7E:62A5`, `$7E:62C5`, `$7E:62E5`, `$7E:6305`, `$7E:6325`, `$7E:6345`, `$7E:6365`, `$7E:6385`; 0 = idle, non-zero = playing).
- Initialized and cleared by `func_90CC1A` on room entry; populated dynamically by `func_90CF3A`.
