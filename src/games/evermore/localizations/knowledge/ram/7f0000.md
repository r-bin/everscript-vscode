Primary decompressed metatile grid buffer in SNES Bank `$7F` (`$7F:0000`..`$7F:22A8`, ~8.8 KB) representing the complete room map layout.

When entering a new room, `func_CC988D` decompresses the room's tile data from ROM into this buffer. During gameplay, `func_D099FB` samples this grid as the camera moves to refresh the active viewport metatile collision matrix (`$7E:08FA`..`$7E:0A25`) and generate background tilemap layers.
