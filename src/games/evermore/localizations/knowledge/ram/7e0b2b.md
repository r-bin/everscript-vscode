Tracks the state of the branching choice selection box during interactive dialogue prompts:
- `0`: Inactive / No choice prompt
- `1`: Box opening and composing option strings
- `2`: Active selection loop (reading player D-pad cursor)
- `3`: Choice confirmed by player; dismissing box
