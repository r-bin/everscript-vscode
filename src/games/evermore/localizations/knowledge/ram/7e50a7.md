Spatial Y-axis bucket table for the engine's elevation/Z-index sorted sprite display list.

Layout:
- 16 vertical screen partition buckets (each covering 64 vertical scanlines) plus 1 root sentinel bucket node (`$7E:5127`).
- Each bucket entry is 8 bytes (`struct SpriteBucketNode`):
  - `+0x00`: Prev node pointer
  - `+0x02`: Next node pointer
  - `+0x04`: Sentinel sort key (`$FFFE` for root, `$FFFF` for empty bucket tails)
  - `+0x06`: Tail node pointer

At the beginning of each frame, `func_C09685` resets the bucket headers and resets the dynamic draw node allocation pointer (`$7E:1276`) to `$7E:512F`.
