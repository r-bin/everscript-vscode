5-byte bitfield (35 bits) recording whether each of the 35 alchemy formulas has been learned by the player.

Bit allocation order is alphabetical:
- `$7E:2258`: bits 0..7: Acid Rain, Atlas, Barrier, Call Up, Corrosion, Crush, Cure, Defend
- `$7E:2259`: bits 0..7: Double Drain, Drain, Energize, Escape, Explosion, Fireball, Fire Power, Flash
- `$7E:225A`: bits 0..7: Force Field, Hard Ball, Heal, Lance, Laser, Levitate, Lightning Storm, Miracle Cure
- `$7E:225B`: bits 0..7: Nitro, One Up, Reflect, Regrowth, Revealer, Revive, Slow Burn, Speed
- `$7E:225C`: bits 0..2: Sting, Stop, Super Heal
