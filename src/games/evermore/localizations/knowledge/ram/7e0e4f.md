Parameter register used to deliver sound effect (SFX) IDs to the APU.

Written by `play_sound_effect_a_driver_effect_does` (`$8C:82DC`), which handles sound playback invoked by script opcode `0x30` (`sound`) and animation command `sound n`. The routine places the sound effect index in `$0E4F`, sets register `A` to `$0004`, and executes the spinlock handshake via `apu_handshake_2140_spinlock` (`$8C:81FD`) to signal the SPC700 sound driver.
