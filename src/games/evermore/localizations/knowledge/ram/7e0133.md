Four 16-bit words that hold the game's random number generator. Every call to `$80:859B`
stirs all four and hands back a fresh value from `$0133`. Anything random (shake, and 16 other
callers) draws from here, so writing these bytes makes the following "random" events repeatable.

## Notes
The seed depends on exactly when the reset code reads the PPU counters, so two emulators (or
snes9x vs. the snesrecomp build) start with different values. Lockstep comparisons must copy
this state from one side to the other first. Not yet checked whether a save or room change reseeds it.

## For script simulation
Scripts see a value only if no engine draw happened since the last known state. The engine
draws between scheduler passes almost every tick, so `src/games/evermore/simulation` treats the state as
unknown at each tick unless it is told (a trace or snapshot). Within one pass, consecutive
script draws are exact (`src/games/evermore/simulation/rng.ts`, checked by `scheduler.test.js`).
