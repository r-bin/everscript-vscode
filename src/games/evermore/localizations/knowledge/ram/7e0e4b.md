Holds the currently loaded / playing Background Music (BGM) track ID.

When script opcode `0x33` (`music`) or a map load requests a BGM track, the engine calls `song_soundbank_validation_loader` at `$8C:8261`. The routine checks whether `$0E4B` already matches the requested track ID; if so, it exits without reloading the soundbank, preventing audio glitching and playback restarts. If the track differs, it looks up the 24-bit soundbank pointer in `tbl_song_pointer_table` (`$C1:9903`), initiates the SPC700 IPL bootloader transfer sequence, and updates `$0E4B`.
