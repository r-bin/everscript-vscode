A room lists up to 14 map palettes ("tile families") but the PPU has only 7 BG palettes for them.
This value is the index of the first one to load: 0 loads the first set, 7 the second. Scripts
change it to swap a room's colours (day/night, a boss's palette); when it differs from the set
already loaded (`$0F8A`) the palettes and their tiles are reloaded. A second set with fewer than 7
entries loads only those; the remaining BG palettes keep their colours.
