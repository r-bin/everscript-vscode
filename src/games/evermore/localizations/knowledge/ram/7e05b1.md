16-word (32-byte) staging buffer holding decoded font tile indices for the active dialogue or menu line currently being rendered.

Populated by `expand_window_text_tokens` (`$8C:9E03`) when script opcode `0x51` (`dialogue`) or modal window handlers decode text tokens, ASCII digraphs, or currency values. The resulting words are transferred into VRAM tilemap buffers for display.
