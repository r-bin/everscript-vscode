8-bit bitmask indicating which battery-backed SRAM save slots contain valid game data:
- Bit 0: Slot 0 valid (payload checksum matches header).
- Bit 1: Slot 1 valid.
- Bit 2: Slot 2 valid.
- Bit 3: Slot 3 valid.

Populated during cold start / reset sequence by `func_8DC905`: iterates through all 4 save slots, computes the 16-bit rotational CRC across 815 bytes of save state payload, and sets the corresponding bits in `$7E:0B39` for the save slot selection screen.
