Active viewport metatile collision matrix describing the local 16×16 tile terrain surrounding the camera and active party in the current room.

Layout:
- `$7E:08EE`: Viewport row pitch / byte stride factor
- `$7E:08F8`: Base descriptor / row pitch parameter
- `$7E:08FA`..`$7E:0A25`: 16 rows of 16-bit metatile collision descriptors

Populated by `func_D099FB` whenever the camera scrolls across metatile boundaries. Each 16-bit entry defines impassable walls, water surfaces, stairs, ledges, and elevation layers tested during player and companion physics steps.
