Inter-room duct transit register holding the sector / portal index (1..17) through which the Boy enters the Omnitopia Metroplex duct system (Room 72).

Written by exterior Omnitopia room duct triggers before invoking `load_map(OMNITOPIA_METROPLEX, 15, 17)`. In Room 72, `OMNITOPIA_DUCT_SETUP_ENTRANCE` (`rom/9ad5c8`) switches on this index to determine the exact duct shaft entry coordinates (`TRANSIT_ORIGIN_X`, `TRANSIT_ORIGIN_Y`) and the entry grate object ID (`DUCT_ENTRANCE_GRATE_OBJECT` in `$7E:24F9`).

Wholly transient inter-room handshake variable with zero persistence benefit; prime candidate for scratch memory (`<0x2834>`).
