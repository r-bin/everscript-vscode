| offset | size | meaning |
|---|---|---|
| +0 | 3 | pc (24-bit), saved when the thread's turn ends |
| +3 | 2 | state: 0 free, 2 running, 4 sleeping, 6/8/10/12 waiting (see `rom/8ccffd.md`) |
| +5 | 4 | sleep deadline against the timer `$0B19` (or the waited-for value) |
| +9 | 2 | bits a state-6 wait expects |
| +B | 2 | caller's slot (0 for a thread's first script) — a call takes a slot of its own |
| +D | 2 | owner entity ("script owner"); calls and started scripts inherit it |
| +F | 20 | ten argument words, copied from `$0E80` at allocation |

The first free slot is always taken, so slot numbers are predictable.
