Interaction state bitfield for the secret critters at the Nobilia Market entrance (Room 10, object 0x27):

- Bits 1+ (`value >> 1`): Interaction counter for the bouncing critter; advancing this counter causes the creature to leap, heal, and detonate via `CRITTER_EXPLOSION_EFFECT` (`rom/96b07e`).

Local to Room 10; ideal candidate for scratch memory (`<0x2834>`).
