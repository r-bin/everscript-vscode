The first entity slot; every slot (and the Boy's and Dog's longer records) has this layout. Code
reaches a record through X or Y (`LDA $001A,y`), so C uses the offsets below as
`ENTITY_RECORD_<FIELD>_OFF` (`soe_ram.h`), not this slot's address.

## Fields
| offset | size | name | meaning |
|---|---|---|---|
| +$00 | 3 | ANIM_PTR | animation script resume pointer (24-bit) |
| +$03 | 2 | ANIM_RESTART | the animation's restart point (word of its table entry) |
| +$05 | 1 | ANIM_TIMER | animation frame timer |
| +$06 | 2 | SPRITE | current sprite: address in its bank |
| +$08 | 1 | SPRITE_BANK | that bank ($A8 + opcode / 2, anim_op_sprite $90:8418) |
| +$0C | 2 | PALETTE_SLOT | palette slot; 0 adds $0200 to the sprite attributes |
| +$10 | 2 | FLAGS | spawn flags: $0002 invincible, $0004 party, $0020 inactive, $0400 phasing |
| +$12 | 2 | STATE | state bits; bit 0 set when a collision step succeeded ($8F:AF0E) |
| +$14 | 2 | CLOSED_STATES | states the hit test skips (& $070D); bit 8 = not targetable |
| +$16 | 2 | MODE | mode: $01 knockback, $04 walking, $08 running, $10 attacking, $20 casting/dodging |
| +$18 | 2 | PLANE | elevation plane (& $0030), bit 6 plane-transparent |
| +$1A | 2 | POS_X | x in pixels |
| +$1C | 2 | POS_Y | y in pixels |
| +$1E | 2 | HEIGHT | height in 1/16 px |
| +$20 | 2 | VSPEED | vertical speed |
| +$22 | 2 | FACING | facing (8 = south) |
| +$24 | 2 | AI_TARGET | the record this AI goes for, 0 = none |
| +$2A | 2 | HP | hit points; 0 = not active (ai_pick_target skips it) |
| +$2E | 2 | STAMINA | stamina / charge meter, full at $0400 |
| +$36 | 2 | LAST_ATTACKER | last attacker |
| +$38 | 2 | ATTACKER_COOLDOWN | cooldown for that attacker |
| +$3A | 2 | TILE_UNDER | the metatile under the feet |
| +$3C | 2 | TILE_COLLISION | that metatile's collision word |
| +$42 | 2 | HURT_DX | hurt region offset x |
| +$44 | 2 | HURT_DY | hurt region offset y ($FFF0 at rest) |
| +$5E | 2 | NEXT | next record in the entity list (0 ends it) |
| +$60 | 2 | CHARACTER | the character record ($8E:0000 + this) |
| +$6A | 2 | CHILD_SLOT | multipart child slot, negative = none |
| +$76 | 2 | PENDING_DAMAGE | damage waiting to be applied |
| +$82 | 2 | TICK_HANDLER | selects the per-entity routine of the entity pass ($8F:C618 table) |
| +$84 | 2 | SPRITE_DEPTH | sprite depth (0 = hidden) |
| +$86 | 2 | SEGMENTS | segment list pointer (segmented bodies) |
