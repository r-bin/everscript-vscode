32-byte array containing destination CGRAM color indices for 32 dynamic color animation channels:
- Channel X (0..31) controls animated color pulsing, lava glows, waterfall shimmer, or dynamic object palette cycling.
- In `func_90D58C`, `LDA $1372,X` specifies the base CGRAM word offset (`$2E`) written to CGADD (`$2121`).
- Added to `$7E:6187` to locate the source 15-bit RGB color word in the master WRAM palette buffer.
