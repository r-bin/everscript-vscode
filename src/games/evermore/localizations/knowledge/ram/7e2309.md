Four contiguous 24-bit currency balances stored in Working RAM and saved in SRAM:
- `$7E:2309`..`$7E:230B`: **Talons** (Prehistoric era, 3 bytes, up to 16,777,215)
- `$7E:230C`..`$7E:230E`: **Jewels** (Antiquity era, 3 bytes)
- `$7E:230F`..`$7E:2311`: **Gold Coins** (Medieval era, 3 bytes)
- `$7E:2312`..`$7E:2314`: **Credits** (Omnitopia era, 3 bytes)

Converted via script opcode `0x7E` (`$8C:D5AA`), added via opcode `0x7C`, subtracted via opcode `0x7D`, and tested via opcode `0x0A`.
