Command node allocation arena for the engine's dynamic Y-sorted metasprite renderer.

Occupies `$7E:512F` through `$7E:6288` (~4.5 KB, capacity for ~300 active sprite draw nodes per frame).

Node layout (`stride=15` bytes):
- `+0x00`: Next node pointer in sorted chain
- `+0x02`: Prev node pointer in sorted chain
- `+0x04`: Sort key = Screen Y coordinate (16-bit word)
- `+0x06`: Screen X coordinate (`$7E:0002`)
- `+0x08`: Screen Y coordinate (`$7E:0004`)
- `+0x0A`: Attribute / priority / palette flags (`$7E:0006`)
- `+0x0C`..`+0x0E`: 24-bit pointer to metasprite frame data in ROM (`$7E:0026`..`$7E:0028`)

During `func_C096BB` (invoked during `per_frame_field_tick`), the engine walks this list in ascending Y order to construct OAM entries with accurate sprite layering and priority.
