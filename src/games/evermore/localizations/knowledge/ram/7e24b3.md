Initial vertical launch / upward impulse speed parameter in subpixels (fixed-point 12.4).
Set by trigger scripts prior to calling the trajectory animation routine `$94:AC56` or local well/chute falling scripts (e.g., values 2, 0x2A, 0x33, 0x4A). The simulation inverts this value to establish initial upward velocity (`TRAJECTORY_VY = -signed TRAJECTORY_INITIAL_VY`).

This is a transient call argument with zero persistence benefit across saves or rooms; it belongs in `<0x2834>` (`temp[]`).
