WRAM staging buffer for dynamic 8x8 4bpp SNES sprite tiles queued for transfer to VRAM.

Structure:
- Stride: Exactly 32 bytes (16 words) per 8x8 4bpp SNES tile.
- Span: `$7E:6C91` to `$7E:72D0` (capacity for ~50 distinct dynamic 8x8 tiles).
- Populated by `obj_tile_allocate` (`$C0:A4B5`). When an entity animation requests a sprite tile not currently resident in VRAM, the routine decompresses or copies the 32-byte tile pattern into this buffer before scheduling a DMA transfer into SNES VRAM tile slots.
