# weapon_mastery_skill_level_experience_tick

Awards weapon mastery proficiency points on hit procs, checking milestone thresholds for weapon level up.

## Metadata
- **Address:** `$8F:973E`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 115 bytes

## Functionality
Awards weapon mastery progression when striking enemies with physical weapons or projectile consumables.
The routine retrieves the equipped weapon category offset from `$0ABA`, increments weapon experience in `$0ADD,X`, and checks for level boundaries (Level 1, 2, 3).

When crossing a 100-point boundary (e.g. `$0100`, `$0200`), it enqueues the weapon level-up celebratory banner and fanfare via cutscene script launcher `$8C:C521`.

## Variables and Memory
- `$0ABA` (Active equipped weapon type index)
- `$0ADD,X` (Weapon mastery experience points table)
- `$12` (Weapon level milestone comparison register)
