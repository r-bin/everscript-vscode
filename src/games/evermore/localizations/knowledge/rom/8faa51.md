Takes a 16-bit value holding two signed bytes (H high, L low) and returns an even direction index 0..14 in A, going around a circle in steps of 2.

## Values
| H | L | result |
|---|---|---|
| 0 | + | 4 |
| + | + | 6 |
| + | 0 | 8 |
| + | - | 10 |
| 0 | - | 12 |
| - | - | 14 |
| - | 0 | 0 |
| - | + | 2 |

(0,0) also returns 0. Which byte is X and which is Y is not yet determined; the callers are the companion steering code, so the pair is probably a position delta.
