Handler of script opcode [0xB5](soe://rom/assets/scripts/opcodes/b5.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/b5.md`, served at `soe://rom/assets/scripts/opcodes/b5.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$90:DCC0`
- Reads ROM: `$90:D986` in Projectile movement routines (+$1F)
- Opcode table entry: `$8C:EA27` (0xb5)

The parameter staging and movement-table lookup are documented in [opcode-b5-projectile.md](../../../../../../docs/disassembly/script-vm/opcode-b5-projectile.md) and modeled in `reconstructed-c/8C/8CE81B_opcode_b5_projectile.c`.
