Evaluates an entity expression and two coordinate expressions, stages the coordinates in DP `$46`/`$48`, and enters the shared position path with mode 0. That path calls `$8F:AA82` to request movement; this opcode does not directly write the entity's coordinates. Returns Carry Set. The exact rules applied by the movement helper are documented with opcode `0x6C`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
- Opcode table entry: `$8C:E9F7` (0x9d)
