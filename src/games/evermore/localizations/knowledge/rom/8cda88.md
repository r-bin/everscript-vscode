Entity, x and y pixel expressions; the shared path `$8C:DAA6` queues a walk through `$8F:AA82`, which resolves the destination's elevation (`$90:9815`, `$8F:A93B`) like opcode `0x6C`. A dead entity other than Boy/Dog is skipped. Returns Carry Set.

Previously named `teleport`: it walks.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
- Opcode table entry: `$8C:E9F7` (0x9d)
