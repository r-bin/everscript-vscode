Sets up the colour cycle of one palette (X): `$1372` = palette * 8 + first colour, `$13D2` = speed (0 = off; negative runs backwards), `$13F2` the step, `$1392`/`$13B2` the colour count by direction. Used by script opcode `0xB6`.
