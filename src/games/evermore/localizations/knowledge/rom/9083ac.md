# entity_collision_and_animation_script_reset

Terminates active entity script threads, zeroes script registers, and resets collision override flags.

## Metadata
- **Address:** `$90:83AC`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 108 bytes

## Functionality
Cancels active event scripts running on an entity and resets action states.
The routine inspects script thread registers in `$88,Y` and `$8A,Y`. If a script is attached, it calls `$8C:CFF4` to kill the script thread and clears the register words.

It also clears animation override flags in `$68,Y` and resets action state `$2A,Y`, returning the actor to neutral idle state.

## Callers
- Entity cleanup and script termination routines in Bank `$90`

## Callees
- `$8C:CE4D` (`FUN_8cce4d`)
- `$8C:CFF4` (`FUN_8ccff4`)

## Variables and Memory
- `$88,Y`, `$8A,Y` (Entity event script thread execution pointers)
- `$68,Y` (Entity animation script override status flags)
- `$2A,Y` (Entity action/combat status state word)
