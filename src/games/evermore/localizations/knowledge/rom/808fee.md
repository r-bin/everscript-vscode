Finalizes the Low and High OAM hardware buffers (`$7E:ABDE` and `$7E:ADDE`) at the completion of an active game frame:
- Compares the current Low OAM write cursor (`DP $D3`) against the previous frame's allocation high-water mark (`$7E:1438`).
- If fewer sprites were emitted than the previous frame (`$D3 < $1438`), iterates through every deallocated 4-byte OAM slot and writes `0xE0E0` (Y-coordinate 224, offscreen at the bottom of the 224-line NTSC active display), preventing stale phantom sprites from persisting on screen.
- Updates `$7E:1438` with the new cursor position.
- Null-terminates both dynamic OBJ VRAM DMA staging queues at `$7E:15D6,X` (indexed by `DP $CB`) and `$7E:163C,X` (indexed by `DP $CD`).
- Resets the active Low OAM cursor `DP $D3` to zero for the subsequent frame's sprite generation pass.
- Re-arms buffer boundaries: `DP $D5 = 0x01FF` (511 bytes Low OAM capacity) and `DP $D7 = 0x40` (64 bytes High OAM capacity).
- Sets `DP $D9 = 0x0001` (frame OAM dirty/ready latch), signaling the NMI VBLANK handler to execute the hardware DMA transfer to the PPU OAM register (`$2104`).
