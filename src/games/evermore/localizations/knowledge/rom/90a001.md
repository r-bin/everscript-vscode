Helper for script opcode `0x96` (`Teleport player by X, Y screens`).

Converts screen delta arguments to 512-pixel increments:
1. Adds `dx` and `dy` offsets to camera registers `DP $BF` and `DP $C1` unconditionally.
2. Iterates active entities linked list starting at `$7E:3DDF`.
3. For each entity, adds the offset to `entity +$1A` and `entity +$1C`.
4. Tests destination passability via `JSL $90:9561`.
5. If destination is passable, commits new position via `JSL $8F:C2E4`.
6. If destination is impassable/solid (`BCC` at `$90:A09B`), skips `JSL $8F:C2E4`—the entity remains at its current position while the camera moves.
