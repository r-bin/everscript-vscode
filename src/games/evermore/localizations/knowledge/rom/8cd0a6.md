Loop: fetch the opcode byte through the 24-bit script pointer at DP $82-$84 and advance it, double it, JSR through the handler table at $8C:E8BD (one word per opcode, same bank). Repeats while the handler returns carry set, then writes the pointer back to the slot at X = DP $7E (words $82 → X+0, $83 → X+1; skipped when the word at $83 is 0). Seen in the REA/Ghidra spike, v0.201.6.
