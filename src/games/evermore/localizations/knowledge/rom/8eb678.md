The record the game builds an entity from. Its address (bank `$8E`) comes from the ENEMY table
`$8E:B55A`; the new entity keeps it at `+$60`, and later code reads the record through that. The
Boy (`$0A26`) and the Dog (`$0A70`) have theirs in WRAM, reached through the same long reads (bank
`$8E` mirrors low WRAM). Each field with its decompiled code: `docs/entities/character-properties.md`.

| field | read by | what the game does |
|---|---|---|
| `+$00` (24-bit) | `$8C:89FD` | pointer to the name, shown in the target window; the Boy's and the Dog's point at their WRAM name buffers |
| `+$03` | `$8F:CD1A` | behaviour: read live on every idle tick, index into the jump table `$8F:CBE0` (not copied at spawn) |
| `+$05` | `$8F:B0C3` | OR'd into entity flags `+$10`: bit 1 = touching it runs no contact handler (`$8F:B564`), bit 5 = left out of targeting (`$8F:D8D2`, `$8C:F184`) |
| `+$07` | `$8F:C4BA`, `$8F:BA46`, `$8C:8658`, `$8F:B9FB` | bit 0 side record at `$58AF`, bit 1 −30 hit against the AI partner, bits 2–3 target filter, bit 4 projectile immunity |
| `+$09` / `+$0B` | `$90:CD1B` / `$90:CD01` | palette addresses in bank `$90`; with `+$0B` set both go to sprite slots 0 and 1, otherwise `+$09` gets a shared slot (`$90:CD80`) |
| `+$0D` | `$8F:B4AB`, `$8F:B651`, `$8F:DA10` | radius: body overlap, strike boxes, and the attack-reach width of a target |
| `+$0F` | `$8F:B15B`, `$8F:C0AC`, `$8F:91E0`, `$91:A773`, `$91:B181`, `$91:B47A` | maximum HP: spawn HP, the heal cap, the HUD's maximum, full heal, +1 regeneration (status $40), poison ticks of max/16 (status $90) |
| `+$11` | `$8F:B162` | copied into entity `+$2C`, which no recorded CPU code reads |
| `+$13` | `$8F:D6B3`, `$8F:D9D1` | engage distance (a square) and attack reach (a plus sign) |
| `+$15` | `$8F:D6AD` | engage chance per tick: `(rand & $FF) < +$15` |
| `+$17` | `$8F:B169`, `$8F:DEAB` | leash radius → entity `+$40` (`$8F:DAA7`), unless `$23DD` ≥ 0 |
| `+$19`, `+$1B` | `$8F:C042`, `$8F:C072` | attack (scaled by charge), defence (/4) |
| `+$1D` | `$91:9CB3`, `$91:9CD0` | magic defence: subtracted for the party, `($40 − m)/$40` (signed byte) for enemies |
| `+$1F`, `+$21` | `$8F:BA27`, `$8F:BA53` | evade row and hit column of the hit table `$8F:BAAF` |
| `+$19`-`+$21` | `$8C:8AAC`-`$8C:8B5A` | also shown by the target stats card `$8C:8A25` |
| `+$23` (32-bit), `+$27`, `+$29` (byte) | `$8F:8292`, `$8F:868E`, `$90:8567` | experience, money (current era's currency), drop chance /128 |
| `+$2A` | — (`$0A50`, `$0A9A` absolute) | level of the Boy and the Dog; enemy records hold 1–50, which nothing reads |
| `+$2C` | `$91:AEDE`, `$8F:CDB1` / `$8F:CEE4` (absolute) | charge limit: cap of a held charge and of the Speed status |
| `+$2E` | `$8F:CC5D`, `$8F:CDAA` / `$8F:CEDD` (absolute) | charge speed: added a tick up to `$400`; −3 a tick past it while held |
| `+$30` | `$8F:B575`, `$8F:B5D3`, `$8F:B5EB` | attack proc: what its contact and its strikes do (table `$8F:B6AE`) |
| `+$32`-`+$48` | `$90:8240`-`$90:8317`, `$8F:C1D6`, `$8F:C2C4`, `$90:8587` | animation ids: stand, walk, run, four attack levels by charge, knockback, death, death with a drop, cast, dodge |

The Boy's and the Dog's WRAM records are rewritten by the weapon (`$8F:81C9`: `+$13` reach,
`+$32`-`+$48`, `+$09`, `+$2C` = weapon level × `$400`) and Dog form (`$8F:9471`) loaders, and by
the Dog's attack level (`$8F:97C0`: `+$2C`).
