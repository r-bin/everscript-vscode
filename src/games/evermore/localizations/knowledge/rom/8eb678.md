The record the game builds an entity from. Its address (bank `$8E`) comes from the ENEMY table
`$8E:B55A`; the new entity keeps it at `+$60`, and later code reads the record through that.

| field | read by | what the game does |
|---|---|---|
| `+$00` (24-bit) | `$8C:89FD` | pointer to the name, shown in a text window; the Boy's and the Dog's point at their WRAM name buffers |
| `+$03` | `$8F:CD1A` | picks the AI script |
| `+$05` | `$8F:B0C3` | OR'd into entity flags `+$10`: bit 1 = touching it runs no contact handler (`$8F:B564`), bit 5 = left out of targeting (`$8F:D8D2`, `$8C:F184`) |
| `+$07` | `$8F:C4BA`, `$8F:BA46`, `$8F:B9FB`, `$8C:86A6` | more flags (list registration, hit-rate penalty, projectile immunity, script tests) |
| `+$09` / `+$0B` | `$90:CD1B` / `$90:CD01` | palette addresses in bank `$90` (`$90:CF3A` loads colours 1-15) |
| `+$0D` | `$8F:B4AB`, `$8F:DA10` | radius: overlap when \|dx\| < r1+r2 and 2·\|dy\| < r1+r2 |
| `+$0F` | `$8F:B15B` | HP, copied into entity `+$2A` |
| `+$11` / `+$17` | `$8F:B162` / `$8F:B169` | copied into entity `+$2C` / `+$40` |
| `+$13`, `+$15` | `$8F:D72D`, `$8F:D6AD` | engage range and chance |
| `+$19`-`+$21` | `$8F:C042`, `$8F:BA27`, `$8F:BA53` | attack, defence, magic defence, evade, hit rate |
| `+$23` (32-bit), `+$27`, `+$29` | `$8F:8292`, `$8F:868E`, `$90:8567` | experience, money, drop chance |
| `+$2C`, `+$2E` | `$91:AEDE`, `$8F:CC5D` | charge limit and speed |
| `+$30` | `$8F:B575` | what touching it does (table `$8F:B6AE`) |
| `+$32`-`+$48` | `$90:8240`-`$90:8317`, `$8F:C1D6` | animation ids: stand, walk, run, four attack levels by charge, knockback, death, death with a drop, cast, dodge |

The Boy (`$0A26`) and the Dog (`$0A70`) have their records in WRAM, rewritten by the weapon
(`$8F:81C9`) and Dog form (`$8F:9471`) loaders.
