Retrieves or allocates a primary child attachment entity for a parent (such as a boss segment, weapon, or shadow).
If `parent->primary_child` (`entity + 0x6A`) is already valid, returns the existing slot index.
Otherwise, pops an available slot from the free list at `$7E:3BC7`, sets bidirectional parent-child references, clears state flags `$7E:3C12,X`, and initializes the waypoint navigation anchor via `$8F:9937`.
