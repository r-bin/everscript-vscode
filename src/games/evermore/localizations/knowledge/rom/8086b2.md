Streams memory blocks to SNES PPU VRAM with custom VMAIN increment mode:
- Configures PPU Video Port Control Register `VMAIN` (`$2115`) from register `Y`.
- Sets destination word address `$2116` (`VMADD`) from DP `$2E`.
- Increments and decrements VRAM lock flag `$7E:0F3A`.
- Fires DMA Channel 1 (`$420B = 0x02`) in 2-register mode (`0x1801` to `$2118`/`$2119`).
