Handler of script opcode [0x5F](soe://rom/assets/scripts/opcodes/5f.md). Evaluates an object index, loads the low-byte target state at `$7E:107E,X`, evaluates an increment expression, adds it using 16-bit accumulator arithmetic, and delegates the resulting target to `$90:A36D`. Returns carry set. Unused by original scripts (0 statically reachable instructions). Host-side model: `docs/disassembly/script-vm/opcode-5f-add-object-state.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$90:A36D`
- Reads WRAM: `$7E:107E`
- Opcode table entry: `$8C:E97B` (0x5f)
