Evaluates an address expression followed by a value expression, then writes the value as a 16-bit word to that address in the current `$7E` data bank. Returns Carry Set. The script supplies the address; this handler performs no bounds check.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$00`
- Opcode table entry: `$8C:E9B1` (0x7a)
