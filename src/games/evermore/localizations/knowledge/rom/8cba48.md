# ui_window_aspect_ratio_scaled_box_draw

Calculates scaled UI window aspect ratio bounds and coordinates using hardware math registers.

## Metadata
- **Address:** `$8C:BA48`
- **Type:** `routine`
- **Bank:** `$8C`
- **Size:** 99 bytes

## Functionality
Scales window dimensions for proportional dialogue boxes and shop interfaces.
The routine loads window width in `$36,X` and height ratio in `$2E,X`, computing proportional dimensions using SNES hardware division registers `$4204`/`$4206` and multiplier `$4202`.

It derives scaled column and row coordinates, preparing tile boundaries for menu border rendering.

## Callers
- `$8C:BA86` (`FUN_8cba86`)

## Callees
- None

## Variables and Memory
- `$36,X` (Input base window pixel width)
- `$2E,X` (Input aspect ratio scale factor)
- `$4204`, `$4206` (Hardware division registers)
- `$4202`, `$4216` (Hardware multiplication registers)
