The party's records start as copies of character records 0 (Boy) and 1 (Dog). From then on the
game changes them in WRAM, and the enemy index points at the WRAM copies (`$0A26`, `$0A70`).

A move of the character table has to change this block move's source bank too. It names banks, not
an operand, so an operand scan does not find it.
