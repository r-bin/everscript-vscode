# shopkeeper_dialogue_show_confirm_buy_box

Displays the confirmation prompt window for purchasing items or equipment in shops, showing the price.

## Metadata
- **Address:** `$8E:A885`
- **Type:** `routine`
- **Bank:** `$8E`
- **Size:** 87 bytes

## Functionality
Builds the purchase confirmation prompt when buying an item from a merchant.
The routine closes previous ring menus via `$8E:AE85`, initializes the dialogue text box tilemap via `$8C:AF2B`, retrieves the item price and name from ROM table `$8E:8000,X`, appends formatted text via `$8C:9E03`, and awaits confirmation via joypad input handler `$8E:ADBC`.

## Callers
- Shop buy transaction loops in Bank `$8E`

## Callees
- `$8C:9E03` (`dialogue_format_and_append_line`)
- `$8C:AF2B` (`window_tilemap_buffer_init`)
- `$8E:990A` (`func_8E990A`)
- `$8E:ADBC` (`func_8EADBC`)
- `$8E:AE85` (`ring_menu_close_and_restore_screen`)

## Variables and Memory
- `$95` (Selected shop inventory item descriptor pointer)
- `$8E:8000` (ROM item shop purchase price lookup table)
