Fast unrolled memory transfer loop for unpacking 4bpp sprite tiles into the dynamic staging buffer:
- Streams graphic tile data from source structures in Y into WRAM staging buffer `$7E:72D1` (`SPRITE_TILE_STAGING_BUF`).
- Highly unrolled with consecutive `STA.L $7E72xx,X` writes to minimize loop overhead and maximize transfer throughput during dynamic animation frame loading.
