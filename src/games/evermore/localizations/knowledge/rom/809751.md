X = block id × 3. Each entry is a 23-bit offset from the pixel base (`$D90000` for 16×16, `$D10000`
for 8×8); bit 23 = compressed. A compressed block is groups of 16 bytes (8 for 16×16, 2 for 8×8),
each a mask byte whose bits, lowest first, mark the group's zero words, then the other words
(`$80:975E`, `$80:A518`). The NMI uploads a 16×16 block's first 64 bytes to its tile and the rest
one OBJ row down (`$80:82A1`), so its tiles are top-left, top-right, bottom-left, bottom-right.

Both tables are full in vanilla. Once moved into a lower bank half they have room for 10922 ids
each. The readers then use the `$F8` / `$F9` form, because a lower half is ROM only in the
`$C0–$FF` banks. Full clean C decompilation: `docs/disassembly/engine-core/screen-flash.md`.
