Simulates advanced weather precipitation particle physics (rain, snow, volcanic ash):
1. Advances dynamic wind sway angle in `$7E:0134` by frequency step `$7E:72D7`.
2. Computes horizontal sway perturbation using 256-step sine lookup table `$80:8800` multiplied by amplitude `$7E:72D5` via SNES hardware multiplier registers `$00:4202` / `$00:4216`.
3. Iterates over 16 particle slots in `$7E:2440`..`$7E:247F`:
   - Checks if particle is in active ground splash animation state (`$7E:2480,X`).
   - Integrates vertical fall velocity (`$7E:72D3`) and horizontal wind drift.
   - Tests impact against ground wrap scanline (`$7E:72DF`); triggers splash or recycling via `$80:9E51`.
