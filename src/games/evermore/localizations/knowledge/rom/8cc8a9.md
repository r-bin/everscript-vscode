The first byte of each 16×16 tile graphic: bit 7 = compressed (dual stream), bits 6..0 = word count − 1
(uncompressed) or the offset where the data stream starts (compressed). `src/games/evermore/maps/chr.ts`
decodes the same format; `maps/render-script-model.js` reads these fetches out of a trace.
