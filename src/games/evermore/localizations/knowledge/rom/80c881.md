# mode7_cockpit_heading_indicator_frame_tick

Advances rotating compass rose sprite frames and updates cockpit heading indicators during Mode 7 flight.

## Metadata
- **Address:** `$80:C881`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 218 bytes

## Functionality
Updates instrument animations during Mode 7 flight sequences.
The routine verifies flight status in `$0E70` (active when between 10 and 20). It advances compass rotation animation counter `$6819` (masking to `$01FE`), and invokes cel tick helpers `$90:80D2` and `$90:81BD` to refresh HUD indicator sprites.
