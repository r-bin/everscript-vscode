Primary room loading orchestrator: silences current sound via APU commands $1A/$1C, resets room camera, collision, and scratch RAM via $90:8E90, launches the room's enter script via $8C:CE99, and executes field frame ticks ($8E:E41E) until system flags $7E:22EA bits 3, 4, 5 (tiles loaded, entities placed, palette fade ready) are all asserted. Also spawns default player/companion scripts when $05A9 bits 1/2 are set.
