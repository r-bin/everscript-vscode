Master dispatch jump table for the Secret of Evermore event script virtual machine.
Contains 256 16-bit ROM addresses within Bank `$8C` corresponding to script bytecode instructions `$00` through `$FF`.
Evaluated by `func_CCD7D1` on every script interpreter execution step.
