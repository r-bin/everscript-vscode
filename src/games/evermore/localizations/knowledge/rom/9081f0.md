# sprite_multi_part_oam_sort_enqueue

Inserts multi-part composite sprite sub-cels into the depth-sorted OAM rendering queue.

## Metadata
- **Address:** `$90:81F0`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 91 bytes

## Functionality
Splits composite entity descriptors into individual sub-cels and queues them for depth-sorted OAM rendering.
For each sub-cel defined in descriptor record `X`, the routine transfers tile indices (`$0C,Y`, `$0D,Y`), screen space coordinates (`$06,Y`, `$08,Y`), and palette attributes into queue record `$1276`, calling `$80:960A` (`oam_depth_sorted_sprite_insert_node`) to insert each part into the proper Y-depth layer.

## Callers
- `$91:9BAA` (`func_919BAA`)
- `$91:A64D` (`func_91A64D`)

## Callees
- `$80:95F9` (`FUN_8095f9`)
- `$80:960A` (`oam_depth_sorted_sprite_insert_node`)

## Variables and Memory
- `$1276` (Active sprite record queue pointer)
- `$06,Y..$0D,Y` (Sprite sub-cel position and tile attributes)
- `$02`, `$04` (Parent entity screen space coordinates)
