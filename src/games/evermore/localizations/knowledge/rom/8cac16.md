Uploads dialogue window frame border tiles, font palette, and cursor sprites to VRAM based on active style index `$0B17`. Reads Bank `$C4` addresses from tables `$8C:AC74` and `$8C:AC5E`, uploads 8 bytes of palette data to VRAM `$0004` via `$80:85FA`, transfers 160 bytes of window border patterns to VRAM `$0B80` via `$80:8650`, and stages 16 bytes of cursor sprite graphics at VRAM `$1F40`.
