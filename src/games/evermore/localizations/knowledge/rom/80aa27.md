Master 16-bit fixed-math table of integer squares ($x^2$) in Bank `$80`.
Contains 256 16-bit unsigned words (512 bytes total, `$80:AA27`..`$80:AC26`) for inputs $x \in [0, 255]$:
- $0^2 = 0$
- $1^2 = 1$, $2^2 = 4$, $3^2 = 9$, $\dots$
- $16^2 = 256$, $64^2 = 4096$, $128^2 = 16384$
- $255^2 = 65025$ (`0xFE01`)

Queried by 2D positional audio spatialization (`$8C:8589`) to calculate Euclidean screen-distance penalties $(\Delta x)^2 + (\Delta y)^2$ without utilizing the slower hardware signed multiplier ports.
