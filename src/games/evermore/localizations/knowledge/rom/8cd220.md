Sleep for expression ticks: wake at timer `$7E:0B19` + n - 1 (32-bit), sets thread state 4 (`SCRIPT_STATE_SLEEP`); duration 0 returns with carry set (`SEC`) and does not yield. Yielding returns with carry clear (`CLC`).

Operands: `E` (tokens: docs/game-research/script-vm/README.md). Flow: ends the thread's turn (resumes after it).

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Reads WRAM: `$7E:0B19` Field frame counter (32-bit); `$7E:0B1B` in Field frame counter (32-bit) (+$2)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$03` (state), `+$05` (wake_tick_lo), `+$07` (wake_tick_hi)
- Opcode table entries: `$8C:E92F` (0x39), `$8C:E933` (0x3b)
