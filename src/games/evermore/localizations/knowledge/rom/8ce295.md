Expression to sound driver command `$2A`, which sets the SPC timer 1 divider that clocks the music: default `$A0` (sent by opcode `0x33` before each song), larger = slower.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:81FD` APU handshake / `$2140` spinlock
- Opcode table entry: `$8C:E9CB` (0x87)
