Validates whether an entity moving in plane `DP $44` is permitted to enter a candidate metatile.
Tests plane bits 5..4 against the destination collision word using `EOR $44`.
If the planes match or if bridge transparency bit 6 allows layer crossing, sets Carry (`SEC`) and returns
success. If an elevation barrier mismatch exists without bridge transparency, clears Carry (`CLC`) to block
movement.
Full disassembly and clean C reconstruction: `docs/disassembly/maps/elevation-transfer.md`.
