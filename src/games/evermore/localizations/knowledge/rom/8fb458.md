Helper routine called by `$8F:B434` for player and companion actors during room entry:
1. Passes entity pointer in DP `$4C` to `entity_set_position_with_z` (`$8F:C2E4`) to set coordinates, recalculate 16x16 tile offsets, and update terrain surface collision flags.
2. Reads the character's animation descriptor pointer from `entity->anim_descriptor_ptr` (`+$60`).
3. Reads the spawn animation tile index from descriptor offset `+0x32`.
4. Streams the idle character sprite tiles into VRAM via `$90:80CE`.

## Addresses
- Target Entity Pointer: DP `$4C`
- Entity Position Setter: `$8F:C2E4`
- Character Animation Descriptor Pointer: `+$60`
- VRAM Sprite Tile Streamer: `$90:80CE`
