# entity_record_state_and_collision_fields_zero

Clears and zeroes all 40 bytes of an entity record structure, resetting position, state, and hitboxes.

## Metadata
- **Address:** `$8F:C554`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 196 bytes

## Functionality
Utility routine for initializing or decommissioning entity slots in the dynamic entity table.
Given entity base pointer in index register `X`, the routine systematically stores zero across all structure offsets (`STZ $00,X` through `STZ $26,X`), resetting coordinates, velocity vectors, status timers, and collision flags.

## Callers
- `$8F:C40F` (`entity_sleep_wake`)

## Callees
- None

## Variables and Memory
- `$00,X..$26,X` (Entity structure memory block, 40 bytes)
