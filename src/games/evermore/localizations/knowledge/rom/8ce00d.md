Entity, x and y expressions (pixels) into DP `$46`/`$48`. An entity with `+$10` bit `$0008` is not moved. Otherwise `$8F:C2D1` moves it at once; when the one-shot layer override `$23DB` is set (not negative), it is used as the layer (`$44`), reset to `$FFFF`, and `$8F:C2E4` places the entity on that layer.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:C2D1`; `$8F:C2E4`
- Reads WRAM: `$7E:23DB` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$1DB)
- Writes WRAM: `$7E:23DB` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$1DB)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$10`
- Opcode table entry: `$8C:E943` (0x43)
