Calculates the 4-way compass orientation for entity X to face entity Y:
- Determines coordinate deltas:
  - `dx = entity_x[+0x1A] - entity_y[+0x1A]`
  - `dy = entity_x[+0x1C] - entity_y[+0x1C]`
- Calculates absolute values `abs(dx)` and `abs(dy)`.
- If `abs(dy) >= abs(dx)` (vertical axis dominance):
  - If `dy >= 0`: facing = `0` (North)
  - If `dy < 0`: facing = `8` (South)
- If `abs(dy) < abs(dx)` (horizontal axis dominance):
  - If `dx >= 0`: facing = `12` (West)
  - If `dx < 0`: facing = `4` (East)
- Stores resulting direction code (`0, 4, 8, 12`) into `entity_x + 0x22` (`FACE_DIRECTION`).
- Returns facing code in register A.
