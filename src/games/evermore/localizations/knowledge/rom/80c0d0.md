# mode7_scene_subsystems_init_and_map_load

Initializes Mode 7 flight scene graphics, clearing collision queues and loading world map tile patterns.

## Metadata
- **Address:** `$80:C0D0`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 139 bytes

## Functionality
Bootstraps the Mode 7 world map flight scene initiated by script opcode `0x99`.
The routine initializes flight variables, invokes `$80:8CC9` to configure gameplay session memory, clears terrain collision queues via `$80:8860`, and sets initial flight altitude and perspective matrices via `$80:C308` and `$80:C3FC`.

## Callers
- `$80:BC00` (`func_80BC00`)

## Callees
- `$80:8860` (`func_808860`)
- `$80:8CC9` (`gameplay_session_subsystems_init`)
- `$80:C308` (`func_80C308`)
- `$80:C3FC` (`func_80C3FC`)

## Variables and Memory
- `$0E70` (Mode 7 flight operational mode state word)
- `$0E72` (Mode 7 initial focal distance and altitude scalar)
