Handler of script opcode [0x5B](soe://rom/assets/scripts/opcodes/5b.md). Calls `$8C:C609` to synchronously tick field frames while `$7E:0B79` bit `$80` remains set, then activate the next queued dialogue unless bit `$40` is set; returns carry set without yielding.
