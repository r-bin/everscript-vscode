Renders the "current / max" health digits onto the player/target HUD status bar:
1. Verifies if Magic Barrier buff is active in `$7E:2261`; if active, skips updating the standard health readout.
2. Converts numeric `entity->current_hp` (`+$2A`) into decimal digits via `$80:870C`.
3. Emits digit tiles using base index `0x2BEC` followed by the division slash `0x2BF8` (`'/'`).
4. Reads `max_hp` from character descriptor offset `+0x0F` (referenced via `entity->anim_table_ptr` `+$60`) and formats its trailing digits.

## Addresses
- Barrier Buff Flags: `$7E:2261`
- Entity Current HP Field: `+$2A`
- Entity Animation Table Pointer: `+$60`
- Number to Digits Converter: `$80:870C`
