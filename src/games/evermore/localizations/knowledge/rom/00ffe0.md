The 65816 reads its interrupt and reset addresses from bus `$00:FFE0–$FFFF`. They are 16-bit, so
the handler starts in bank `$00`. Evermore leaves bank `$00` straight away:

| vector | target | what runs in bank `$00` |
|---|---|---|
| RESET (emulation) | `$8020` | 13 bytes: force blank (`$2100 = $8F`), native mode, 16-bit A/X/Y, `JML $80:802D` |
| NMI (native + emulation) | `$823A` | `JML $80:823E` (`80823a.md`) |
| IRQ (native + emulation) | `$84EA` | `JML $80:84EE` |
| COP / BRK (native) | `$885E` / `$885F` | `STP`: the game never uses them, and a stray one halts the CPU |
| ABORT, COP (emulation) | `$FFFF` / `$FF00` | never taken (no ABORT pin; emulation mode only during reset) |

Under HiROM these addresses are the slow mirror of file `0x8020+`. A layout that changes what bank
`$00` shows (ExHiROM, SA-1) needs a copy of this table and of these few bytes in its own bank `$00`.
`tools/exhirom/convert.js` finds and copies them, and refuses any entry code that does more than this.
