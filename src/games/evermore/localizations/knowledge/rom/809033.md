Draws one sprite record at screen position `$02`/`$04` with the attribute word `$06`/`$07`: a chunk
count, the offset of the first chunk, an optional culling box, then 5-byte chunks (flags, x, y,
block). Flags bit 0 picks a 16×16 block; bits 1-3, 4-5 and 6-7 become the OAM palette, priority and
flips through the mask. `maps/sprites.ts` reads records this way.
