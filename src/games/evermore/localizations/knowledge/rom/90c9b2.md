Clears status effect bitmask from entity flags at `+$9A,X`. If all status flags cleared, resets status sub-state `+$9E,X`, compares entity against Boy `$0F3E`, and restores default 32-byte sprite palette from `$90:0000 + $0A2F` (Boy) or `+$0A79` (Dog) into staging buffer `$088A` or `$08AA`.
