# sprite_sorting_canopy_occlusion_and_render_depth

Evaluates canopy tile occlusion bit 12 and registers entity priority depth in the OAM sort list.

## Metadata
- **Address:** `$8F:C6C5`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 150 bytes

## Functionality
Determines whether an entity appears in front of or behind canopy ceiling layers.
The routine invokes `$8F:C773` (`Sprite_in_front_of_canopy_bit_12_8FC773`) on the entity\'s current tile.

Based on canopy passability bit 12, it configures sprite priority flags in `$0A,Y`, records Y-depth sorting coordinates in `$08,Y`, and inserts the entity into active OAM render sorting list `$1276` for proper front-to-back hardware sprite layering.

## Callers
- Entity render dispatch loops in Bank `$8F`

## Callees
- `$80:960A` (`FUN_80960a`)
- `$8F:C773` (`Sprite_in_front_of_canopy_bit_12_8FC773`)

## Variables and Memory
- `$4C` (Current entity record pointer)
- `$1276` (Active OAM depth-sorted sprite queue pointer)
- `$06,Y..$0A,Y` (Sprite sorting queue entry: X, Y, and priority flags)
