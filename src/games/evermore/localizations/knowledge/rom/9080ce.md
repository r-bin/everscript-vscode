Tick-level execution loop of the Secret of Evermore sprite animation bytecode VM.
Drives animated sprite sequences for the boy, dog, NPCs, enemies, and weapon/spell effects:
1. Fetches command bytes from the 24-bit instruction pointer in DP `$5D`–`$5F`.
2. Tests bit 7 as the end-of-frame marker, dispatching opcodes `(cmd & 0x7F)` via the `$90:8000` jump table.
3. Decrements the active keyframe hold countdown timer at `slot + 0x05`.
4. When the keyframe timer expires (`0`), writes the advanced instruction pointer back to `slot + 0x00`.
Full disassembly and clean C reconstruction: `docs/disassembly/animation/animation-vm.md`.
