# spell_homing_bearing_and_interpolated_velocity_step

Updates homing spell tracking, interpolating velocity and steering vectors towards target entities.

## Metadata
- **Address:** `$91:9823`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 108 bytes

## Functionality
Advances the steering vector of homing spells (such as Crush or Heat Wave particles).
The routine interpolates velocity step `$0E,X` via `$8E:DFB2` (`entity_linear_interpolation_fixed_point_multiply`).

It calculates relative bearing to the target entity via `$80:AEAC` (`math_vector_2d_angle_and_distance_calc`) and projects updated Cartesian velocity components via `$80:B01D` (`math_fixed_point_sin_cos_multiply`), curving the projectile toward its target.
