Clears `$22EA` bit 0, then branches on `$2391`: `0` sets success and ends; `1` (money) calls
`$92:BEBD`; `0x01xx` are key items (e.g. `0x0101` sets `$2261` bit 6); `0x02xx` ingredients,
`0x04xx` armor and `0x08xx` consumables each test `count + $2461 < cap` and then write
`count = count + 1 + $2461` and set `$22EA` bit 0. A full slot leaves bit 0 clear — the
pickup fails and the trigger's "taken" flag (copied from bit 0) stays clear.

The item → byte map this script encodes is in [ram/7e22ff.md](../ram/7e22ff.md).
