Evaluates an entity and an amount, then calls `$8F:C0A5`. The helper adds the amount to HP at `+$2A`, clamps the result to the entity's maximum from its character record, updates the player HUD for Boy/Dog, and clears pending damage at `+$76` and selected state bits at `+$12`. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:C0A5`
- Opcode table entry: `$8C:E9E7` (0x95)
