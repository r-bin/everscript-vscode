Core SPC700 IPL Bootloader handshake and block streamer. Synchronizes with the SNES sound
coprocessor boot ROM using the standard `$BBAA` ready handshake on ports `$2140`–`$2141`.
Iterates through audio block descriptors, uploads sample and program blocks using the byte-streaming
protocol at `$8C:819E`, and jumps to the SPC700 runtime entry address `0x0700` by writing `0x0000` to `$2141`.
Full disassembly and clean C reconstruction: `docs/disassembly/audio/spc-block-uploader.md`.
