Renders an entity's complete vital and combat statistics card into text window buffer `$0379`
(used by Oracle / Fortune Teller NPCs). If multi-target is selected (`$05AD` bit 0), it rejects the
query with `"I can only talk about one life at a time!\0"`. Otherwise, it streams the entity name,
followed by labels and decimal numeric values for current HP (`$7E:002A,X`), Attack (`+$19`),
Defense (`+$1B`), Hit % (`+$21`), and Evade % (`+$1F`) from the character record in Bank `$8E`.
