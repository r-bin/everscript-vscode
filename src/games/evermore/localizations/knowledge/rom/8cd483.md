Currency offset and amount expressions (the amount's high byte is 0), then the compare of opcode `0x0A`: jumps when the amount at `$0AC6 + offset` is at least the value.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Reads WRAM: `$7E:0AC6`; `$7E:0AC8`
- Opcode table entry: `$8C:E9D9` (0x8e)
