# title_screen_ppu_layer_registers_init

Configures SNES PPU layer registers, tilemap bases, and BG mode 1 for the title screen presentation.

## Metadata
- **Address:** `$80:B3B0`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 86 bytes

## Functionality
Sets up PPU hardware display registers during the game title sequence.
The routine configures sprite size register `$2101` (`#$03`), tilemap base addresses `$2107..$2109`, and character pattern base registers `$210B..$210C`.

It configures SNES BG mode 1 (`$2105 = #$79`), sets window display masks in `$010C`, and enables main screen background layers in `$212C` to present the title graphics.

## Callers
- `$80:B5B6` (`func_80B5B6`)

## Callees
- None

## Variables and Memory
- `$2101` (SNES PPU Object Size and OAM base register)
- `$2105` (SNES PPU BG Mode and Character Size register)
- `$2107..$210C` (SNES PPU Tilemap and Character Base Address registers)
- `$212C` (SNES PPU Main Screen Designation register)
