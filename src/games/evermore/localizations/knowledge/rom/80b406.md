# title_screen_background_graphics_and_palette_dma

Decompresses and DMA transfers title screen background graphics, tilemaps, and palettes to VRAM and CGRAM.

## Metadata
- **Address:** `$80:B406`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 256 bytes

## Functionality
Bootstraps title screen visual assets during the game introduction sequence.
The routine configures source and destination pointers to decompress compressed title graphics from ROM bank `$C6` (`$C6:0100`) into WRAM buffer memory at `$7F:0000` via `$8C:988D` (`decompression_dispatcher_reads_sub_flag`).

It then initiates a DMA transfer (`$80:8650`) of `$4000` bytes to VRAM base address `$2800` for background character patterns, and enqueues the title color palette into CGRAM via `$80:85FA`.

## Callees
- `$80:85FA` (`cgram_palette_dma_enqueue_or_immediate`)

- `$80:8860` (`func_808860`)
- `$8C:988D` (`decompression_dispatcher_reads_sub_flag`)

## Variables and Memory
- `$36`, `$38` (Source compressed data pointer)
- `$3A`, `$3C` (Destination decompressed buffer pointer `$7F:0000`)
- `$26`, `$28` (VRAM DMA source address pointer)
- `$2E` (DMA transfer byte size `$4000`)
