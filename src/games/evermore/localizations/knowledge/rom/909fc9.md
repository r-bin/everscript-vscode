Smooths camera motion by applying a 4-way asymmetric deadzone bounding box to candidate entity coordinates `(A=X, Y=Y)`:
- Left margin: `$7E:240F`
- Right margin: `$7E:2411` (screen width 256)
- Top margin: `$7E:2413`
- Bottom margin: `$7E:2415` (screen height 224)
Adjusts live viewport origin registers DP `$BF` (X) and DP `$C1` (Y) only when the actor exits the deadzone window.
