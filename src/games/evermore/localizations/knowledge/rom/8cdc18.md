Handler of script opcode [0x26](soe://rom/assets/scripts/opcodes/26.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/26.md`, served at `soe://rom/assets/scripts/opcodes/26.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$80:85D8`; `$90:94AB` Camera: centre on the target and clamp to the map bounds
- Reads WRAM: `$7E:0105` in Joypad 1 buttons newly pressed this frame (+$1)
- Writes WRAM: `$7E:0106` PPU register shadows, copied to the PPU every NMI; `$7E:0B83` Screen brightness fade controller
- Opcode table entry: `$8C:E909` (0x26)

## Notes
Previously believed: hypothesized in earlier notes to be a joypad action mask reset. The per-frame
routine at `$80:DE95` confirms that `$7E:0B83` controls the stepped increment/decrement of `$7E:0106`
(`INIDISP` shadow), functioning as the screen brightness fade controller.
