With no operands, copies `$0F80-$0F83` to PPU registers `$212C`, `$212D`, `$2131`, and `$2130`. It clears bit 0 of `$0B29`, then sets that bit when bit 7 of `$7E:22EA` is set. Returns Carry Set.

- Writes WRAM: `$7E:0B29`
- Hardware registers: `$212C`, `$212D`, `$2130`, `$2131`
- Opcode table entry: `$8C:E9C3` (0x83)
