Decompresses and retrieves a localized menu string from string table `$47`. Decodes the string descriptor via `$8C:B81D`: if the resolved string pointer at `[$22]` is empty (first byte 0), invokes fallback handler `$8C:BB72`, reads fallback index `$03DB`, and retries. Dispatches valid string to menu display handler `$80:B173`.
