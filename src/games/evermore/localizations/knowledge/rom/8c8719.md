Builds the list of entities a spell, item or cursor will act on. The game asks for one of four
things: keep the current target if it is still valid, step to the next or previous valid
entity (the target cursor), or take every valid entity at once (an "all enemies" spell). Valid
means `target_candidate_filter` accepts it for the rules in `$05AD`. Nothing here asks whether
an entity is drawn, so an entity that is on screen but invisible can still be picked.

## Entries
| entry | asks for | result in the list at `($0B71)` |
|---|---|---|
| `$8C:8719` | the current target (Y) | Y and a 0, or carry set when Y fails the filter |
| `$8C:8735` | the next valid entity after Y (from the list head when Y = 0) | that entity, or empty with carry set at the end of the list (no wrap) |
| `$8C:8762` | the previous valid entity before Y | the last valid entity met before reaching Y |
| `$8C:879B` | every valid entity | up to 8 entries, 0-terminated; more are dropped in list order |

Because the "all" list holds at most 8 and fills in list order, invisible candidates take
places that visible enemies would otherwise get.
