The text the alchemy menus show: one pointer per formula (`$C4:5D09`, 35 words, formula order,
which is alphabetical), a zero word, then one pointer per formula description (`$C4:5D51`). The
strings are plain ASCII ended by a zero byte, in bank `$C4`. The formula index here is the same
index `$C4:5DDF` (the formula's `$91` block) uses. The Data tab lists them (Enums › Formulas).

## Notes
- Which routine reads the two tables was not traced; the order and count come from the data.
