# spell_projectile_polar_to_cartesian_trajectory_calc

Converts polar heading angle and speed scalar into Cartesian X and Y velocity components.

## Metadata
- **Address:** `$91:CBB1`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 100 bytes

## Functionality
Mathematical conversion utility for launching directional spell projectiles.
Given a directional launch angle (0..255) and scalar speed, the routine queries trigonometric sine and cosine functions via `$80:B01D` (`math_fixed_point_sin_cos_multiply`).

It resolves horizontal velocity `$1A` and vertical velocity `$1C`, applying them to newly spawned projectiles to set initial flight vectors.

## Callers
- `$91:CAFE` (`func_91CAFE`)

## Callees
- `$80:AEAC` (`math_vector_2d_angle_and_distance_calc`)
- `$80:B01D` (`math_fixed_point_sin_cos_multiply`)

## Variables and Memory
- `$02` (Input directional angle)
- `$06` (Input projectile launch speed)
- `$1A`, `$1C` (Output Cartesian velocity vector components)
