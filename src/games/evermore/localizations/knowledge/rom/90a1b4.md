- Decrements countdown timer array `$7E:5018`..`$7E:5049`.
- Advances frame index array `$7E:4FE6`..`$7E:5017` modulated by sequence length from room descriptor `[$A7]`.
- Computes planar VRAM destination addresses from base slot `$7E:106E`.
- Streams 128-byte 4bpp tile data from Bank `$EE` via DMA Channel 1 (`$80:8650`).
- Enforces an amortized limit of 10 tile uploads per frame to prevent VBLANK starvation, deducting costs from DP `$D8`.
