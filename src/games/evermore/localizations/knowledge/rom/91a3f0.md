# spell_projectile_3d_spatial_vector_step

Advances spell projectile 3D coordinates (X, Y, Z elevation) along its velocity vector.

## Metadata
- **Address:** `$91:A3F0`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 287 bytes

## Functionality
Updates the three-dimensional spatial coordinates of active spell projectiles.
The routine subtracts velocity components `$1A,Y`, `$1C,Y`, and `$1E,Y` from current position coordinates `$22,Y` (X-position), `$20,Y` (Y-position), and `$24,Y` (Z-elevation).

It calls `$80:B01D` (`math_fixed_point_sin_cos_multiply`) to recalculate trajectory vectors, advances animation cel frames via `$90:80D2`, and verifies room bounding box limits via `$90:81BD`.

## Callers
- Direct physics dispatch in Bank `$91`

## Callees
- `$80:B01D` (`math_fixed_point_sin_cos_multiply`)
- `$90:80D2` (`func_9080D2`)
- `$90:81BD` (`func_9081BD`)

## Variables and Memory
- `$22,Y` (Projectile 16-bit world X coordinate)
- `$20,Y` (Projectile 16-bit world Y coordinate)
- `$24,Y` (Projectile 16-bit Z-elevation coordinate)
- `$1A,Y`, `$1C,Y`, `$1E,Y` (X, Y, Z velocity delta vectors)
