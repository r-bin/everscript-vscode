Appends the slot in X to the run list at `$2F28` (0-terminated, DP `$86` = its length in bytes), so the
scheduler runs it from the next pass. Used after `$8C:CF18` by thread starts (`0x07`, `0xB4`) and by the
room enter script (`$8C:CE99`).
