Plays a sound effect with dynamic 2D distance attenuation and stereo balance:
1. Calculates screen-centered Manhattan/Euclidean offsets from listener center (`$59+128`, `$5B+112`)
   to sound emitter coordinates (`$02`, `$04`).
2. Queries quadratic distance penalty table `$80:AA27` and logarithmic volume curve `$8C:84D4`.
3. Issues APU IPC Command `0x0036` to play the effect with scaled volume.
4. Computes signed horizontal panning delta, clamps between `-100` and `+100`, and issues APU
   IPC Command `0x003E` across `$2140`–`$2143`.
