Initializes the game font, dialogue window tilemaps, and text rendering subsystem during system startup. Resets PPU registers via `$80:85D8`, initializes font metrics from Bank `$C4` via `font_metrics_table_setup` (`$8C:9DAF`), uploads window border patterns via `$8C:AB10`, and sets up the proportional font blitter via `$8C:B743`.
