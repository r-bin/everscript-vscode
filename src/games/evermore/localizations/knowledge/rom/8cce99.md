Starts the current map's enter script: resets a few script mailboxes, reads the packed pointer at
`$92:801B + 5 * map` (the map id at `$0ADB`; a pointer of 0 means the room has none, see
`script-vm/rooms.ts`), allocates a slot, gives it the entity the camera follows (`$0F42`) as its own
entity, and queues it. The table entry's other two bytes are not read here.
