Master status effect dispatch table in Bank `$91`:
- 8 bytes per status entry:
  - `+0`: Per-frame tick handler pointer
  - `+2`: Cleanup / dispel handler pointer
  - `+4`: Outline glow bit (`$9A,X`)
  - `+6`: Effect classification (`1` = beneficial buff, `2` = harmful ailment)
- Primary status indices:
  - `$00`: Atlas (Attack boost)
  - `$08`: Barrier (Magic defense shield & damage nullification)
  - `$10`: Defend (Physical defense boost)
  - `$18`: Reflect (Magic evade shield)
  - `$20`: Speed (Agility & critical hit boost)
  - `$28`: Force Field (Invulnerability shield)
