# cgram_dynamic_palette_animation_bitfield_scan

Scans active palette animation bitmasks to identify and schedule pending CGRAM dynamic color rotations.

## Metadata
- **Address:** `$90:CA9B`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 280 bytes

## Functionality
Scans active cycling color palette definitions for environmental animations (such as flowing water, glowing lava, or flashing crystals).
The routine examines animated palette bitmasks in `$9C,X` and triggers in `$9A,X`.

When a timer bit matches, it advances the rotation pointer and computes destination CGRAM color palette buffer offsets in `$08A6..$08C8`, queuing the refreshed color entries for DMA upload during the next V-Blank.

## Callers
- `$90:C9FC` (`func_90C9FC`)

## Callees
- None

## Variables and Memory
- `$9A,X` (Palette cycle trigger mask)
- `$9C,X` (Active color rotation shift bitfield)
- `$08A6..$08C8` (CGRAM staging buffers for animated palette entries)
