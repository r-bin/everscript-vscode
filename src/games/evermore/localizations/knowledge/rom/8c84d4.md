Master volume attenuation curve table for real-time 2D sound effect spatialization.
Contains 181 8-bit unsigned bytes (181 bytes total, `$8C:84D4`..`$8C:8588`) defining logarithmic audio volume decay across screen-relative Euclidean distance:
- Index 0: 255 (maximum volume at screen center)
- Final index 180: 0 (audibility cutoff threshold)

Queried by `audio_play_positional_sfx` (`$8C:8589`) following screen delta evaluation and quadratic distance penalty calculation. Transmitted to APU via IPC Command `0x0036`.
