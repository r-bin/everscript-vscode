Reads signed `dx` from DP `$02` and signed `dy` from DP `$04`. The confirmed caller `$8F:D6CE`
sets these to entity position minus target position. Returns the cardinal facing code using the
dominant axis: `$00` north, `$04` east, `$08` south, `$0C` west. For `dy >= 0`, horizontal wins
ties; for `dy < 0`, vertical wins ties. The implementation reproduces the 16-bit `CMP` negative
flag tests. Host C model: `reconstructed-c/80/8080AE78_face_cardinal.c`.
