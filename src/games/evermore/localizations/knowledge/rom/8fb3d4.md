# entity_combat_state_machine_reset_and_reinit

Resets entity action states, clears status condition timers, and reinitializes animation timers.

## Metadata
- **Address:** `$8F:B3D4`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 96 bytes

## Functionality
Restores an entity record to neutral baseline state following combat encounters or cutscenes.
The routine invokes `$90:817B` to reset animation cycle clocks.

It masks out temporary combat flags in `$10,Y`, `$12,Y`, and `$14,Y`, and zeroes status condition timers, projectile anchor links, and target pursuit pointers in `$24,Y` through `$8A,Y`.
