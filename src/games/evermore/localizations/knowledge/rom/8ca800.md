Advances text rendering in dialogue and speech windows character-by-character with typewriter effect:
1. Renders 2bpp character glyph via `dialogue_render_char_glyph` (`$8C:A5A2`).
2. Runs the interactive engine frame tick (`$8E:E41E`) while polling joypad 1 buttons (`$7E:0104`).
3. Upon player action button press (A/B), triggers text audio click sound effect 3 (`$8C:82DC`), checks fast-forward flag `$0621 & 0x0002`, and calculates destination VRAM position (`$8C:A853`).
