# companion_idle_sniff_and_scratch_random_dice_roll

Evaluates companion idle behaviors, rolling RNG to trigger ambient sniffing, scratching, or sitting.

## Metadata
- **Address:** `$8F:AB92`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 91 bytes

## Functionality
Triggers ambient idle animations for the dog companion when stationary.
The routine checks companion movement flags in `$0E,Y`. If stationary across successive frames, it queries random state register `$0E94` and rolls RNG via `$80:859B`.

When triggered, it calls `$8F:AB6E` to select an idle animation sequence (sniffing ground, scratching ear, or sitting), writing the animation index into `$22,Y`.

- `$22,Y` (Resolved animation sequence identifier)
