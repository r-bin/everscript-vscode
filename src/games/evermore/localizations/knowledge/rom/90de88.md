# projectile_linear_flight_position_and_collision_tick

Updates linear horizontal and vertical flight coordinates for non-ballistic projectiles and tests hitboxes.

## Metadata
- **Address:** `$90:DE88`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 86 bytes

## Functionality
Physics step for straight-line projectiles (such as arrows, fireballs, and energy beams).
The routine decrements projectile lifetime timer `$1E,X`. When alive, it adds horizontal and vertical velocity deltas (`$20,Y`, `$22,Y`) to current world position (`$14,Y`, `$16,Y`), advances animation cels via `$90:80D2`, and tests collision against entity hitboxes via `$8F:B5F2`.

## Callers
- Linear projectile physics dispatchers in Bank `$90`

## Callees
- `$8F:B5F2` (`strike_projectile_hit_test_melee_enters`)
- `$90:80D2` (`func_9080D2`)
- `$90:DE7B` (`FUN_90de7b`)

## Variables and Memory
- `$1E,X` (Projectile remaining lifetime frame timer)
- `$14,Y`, `$16,Y` (Projectile horizontal and vertical world positions)
- `$20,Y`, `$22,Y` (Linear velocity delta components)
