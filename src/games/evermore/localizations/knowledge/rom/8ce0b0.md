Handler of script opcode [0x78](soe://rom/assets/scripts/opcodes/78.md). It evaluates the entity expression, fetches the animation word from the script pointer, then evaluates the mode expression. Its gates, state writes, table targets, and distinct mode-10 path are documented in [animate.md](../../../../../../docs/disassembly/script-vm/animate.md).

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Dispatches through: `$8C:E100`–`$8C:E10B` (six-word target table)
- Reads WRAM: `$7E:23D9` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$1D9)
- Writes WRAM: `$7E:23D9` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$1D9)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$10`, `+$12`, `+$2A`, `+$2E`
- Opcode table entry: `$8C:E9AD` (0x78)
