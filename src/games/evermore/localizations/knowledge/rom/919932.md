# projectile_homing_angle_quadrant_bias_calc

Calculates quadrant steering bias flags (clockwise vs counter-clockwise) for homing projectiles.

## Metadata
- **Address:** `$91:9932`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 90 bytes

## Functionality
Mathematical quadrant analysis utility for guiding homing spell trajectories.
The routine samples target heading angle `$44,Y`, performing bitwise shifts and sign checks to determine which quadrant the target lies in.

It returns a binary steering bias in the Accumulator (`#$00` or `#$01`), signaling whether the homing flight algorithm should steer clockwise or counter-clockwise to achieve the shortest angular turn toward the target.

## Variables and Memory
