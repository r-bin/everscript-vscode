An animation id is a byte offset into the records at `$C4:0000`: `[script:u16][bank:u8][flags:u8]`.
Flags bit 7 makes the next eight records one per facing; bit 6 makes four (north, east, south,
west). The record bank's animation fields (`+$32`...) and the global id table `$C4:3C92` both hold
these ids. `maps/animation-vm.ts` `facingScript` follows it.
