Core OAM sprite generator routine.
Checks per-frame VRAM tile streaming budget in DP `$D8` (deducting 3 per tile); invokes `obj_tile_allocate` (`$80:A4B5`) to ensure the sprite tile is cached; formats the 4-byte low OAM entry into buffer `$7E:ABDE` (`X`, `Y`, `tile`, `attrs`), and packs the 2-bit high OAM fields (X position bit 8 and 16×16 size flag) into the 32-byte high table at `$D5`.

## Addresses
- Low OAM Buffer Base: `$7E:ABDE` (512 bytes)
- Low OAM Write Pointer: DP `$D3`
- High OAM Write Pointer: DP `$D5`
- High OAM Packing Mask: DP `$D7`
- Per-frame VRAM upload budget: DP `$D8`
- Dynamic OBJ tile allocator: `$80:A4B5`
