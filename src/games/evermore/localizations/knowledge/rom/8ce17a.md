Word index into the 2-entry pointer table at `$8C:E1FD` (0: `$7E:2210`, 3: `$7E:2234`), then the name entry screen (`$8D:8000`, `$8D:82CB`) edits that buffer and the field comes back. For `$7E:2234` it first copies a default name from `$C4:60AC` (`$80:B149`). The game uses only index 3. Other indexes read past the table.
