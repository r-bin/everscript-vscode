Reads a word operand as an index into paired data at `$8C:E1FD` and `$8C:E1FF`, then runs a fixed field/render transition sequence. It clears `$0106`, sets `$0B83` to `$800F`, and passes the selected data through engine routines; one selected value also takes a special `$80:B149` call path. The table values' semantic names are not established. Returns Carry Set.
