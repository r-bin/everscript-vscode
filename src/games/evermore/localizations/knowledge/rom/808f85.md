Low confidence — Transfers high 9th-bit OAM attribute buffers to hardware staging memory upon V-Blank NMI.

> Inferred from a partial read of the routine; names, purposes and variable roles below are hypotheses until the whole body is traced or tested.

Core SNES hardware display synchronization primitive.
The routine queries display dirty flag `$D9`. If dirty, it clears the flag, unpacks high OAM buffer attributes from `$9726`, and copies size and 9th-bit X sign bits into OAM transfer buffer `$96A5,X`.

This ensures that all multi-cel sprites are committed to hardware Object Attribute Memory during the subsequent NMI V-Blank interval without tearing.
