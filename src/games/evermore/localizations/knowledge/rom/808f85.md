# vram_oam_buffer_dma_commit_on_nmi

Transfers high 9th-bit OAM attribute buffers to hardware staging memory upon V-Blank NMI.

## Metadata
- **Address:** `$80:8F85`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 105 bytes

## Functionality
Core SNES hardware display synchronization primitive.
The routine queries display dirty flag `$D9`. If dirty, it clears the flag, unpacks high OAM buffer attributes from `$9726`, and copies size and 9th-bit X sign bits into OAM transfer buffer `$96A5,X`.

This ensures that all multi-cel sprites are committed to hardware Object Attribute Memory during the subsequent NMI V-Blank interval without tearing.

## Callers
- `$80:858C` (`wait_for_nmi`)
- `$80:C1A2` (`FUN_80c1a2`)
- `$80:C95B` (`FUN_80c95b`)
- `$8F:9817` (`field_spare_time_loop`)

## Callees
- None

## Variables and Memory
- `$D9` (Display / OAM buffer dirty update flag)
- `$9726` (OAM high attribute staging byte)
- `$96A5` (Final hardware OAM upload staging buffer in WRAM)
