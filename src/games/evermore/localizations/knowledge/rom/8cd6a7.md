Plays a sound effect. The one operand byte is a byte offset into the word table at `$8C:8362`
(`SFX_TRANSLATION_TABLE`): a negative entry is silent, any other is the driver's effect number, played
by `$8C:82DC`. Before that, the handler passes `$243B` to the sound driver (command `$30`) and clears it.
The three opcodes share this handler.

Operands: `u8` (tokens: docs/game-research/script-vm/README.md). Flow: continues in the same turn.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$8C:81FD` APU handshake / `$2140` spinlock; `$8C:82DC` Play sound effect (A = driver effect; does not load its package)
- Reads WRAM: `$7E:243B` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$23B)
- Writes WRAM: `$7E:243B` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$23B)
- Reads ROM: `$8C:8362` SFX translation table
- Opcode table entries: `$8C:E91D` (0x30), `$8C:E91F` (0x31), `$8C:E921` (0x32)
