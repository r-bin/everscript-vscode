Animates the ring menu during counter-clockwise rotation:
1. Steps current angle `$7E:061B` by `-4` units per frame.
2. Checks difference against target angle `$7E:061D`. If `>= 4`, continues the frame loop at `$8E:AF54`.
3. When within 4 units of target, triggers selection tick sound effect `0x03` via `$8C:82DC`.
4. Tests controller press register `$7E:0104`: if Left (`0x0100`) is held down, advances to the previous item again and continues smooth continuous rotation.
5. Otherwise, snaps current angle `$7E:061B` to target angle `$7E:061D` and exits via `RTL`.

## Addresses
- Current Orbital Angle: `$7E:061B`
- Target Orbital Angle: `$7E:061D`
- Selection Tick SFX Routine: `$8C:82DC`
- Controller State: `$7E:0104`
