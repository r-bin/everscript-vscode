Returns a diagonal direction code from the signs of DP $02 and DP $04. For arguments mapped
directly to those registers, the outputs are (+,+) -> $06, (+,-) -> $0A, (-,+) -> $0E, and
(-,-) -> $02. Compass labels are not asserted here. The host C reconstruction is in
`reconstructed-c/80/8080AE5C_face_diagonal.c`.
