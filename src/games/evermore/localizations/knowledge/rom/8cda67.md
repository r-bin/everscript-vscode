Evaluates an entity expression, then reads tile X and Y bytes and scales each by 8 into pixel coordinates in DP `$46`/`$48`. The shared helper submits that destination through tile/elevation checks and updates movement state when accepted; the helper also uses the entity's current HP/status to decide whether to proceed. The handler returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
- Opcode table entry: `$8C:E995` (0x6c)
