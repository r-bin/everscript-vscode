Entity expression, then x and y tile bytes, each * 8 into DP `$46`/`$48`. The shared path `$8C:DAA6` skips a non-player entity with 0 HP, then queues a walk through `$8F:AA82` (destination elevation from `$90:9815`/`$8F:A93B`, a move record at `$3C12 + slot`, entity `+$10` |= `$20`). `wait()` (opcode `0x2E`) then waits for arrival. Returns Carry Set.

- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
