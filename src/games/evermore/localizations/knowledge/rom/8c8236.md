Validates whether a requested instrument soundbank is currently resident in SPC700 RAM (`$7E:0E4B`).
If a new soundbank is required, it looks up the ROM sample block from table `$81:9903`, sends APU
preparation command `0x0E`, streams sample data via the IPL transfer routine `$805B`, finalizes with
command `0x02`, and records the active bank ID in `$0E4B`.
Full disassembly and clean C reconstruction: `docs/disassembly/audio/spc-handshake.md`.
