## Addresses

- Calls: `$8C:C521`; `$91:973E`; `$91:9759`; `$91:9777`; `$91:AD17`
- Reads WRAM: `$7E:3BC1`
- Writes WRAM: `$7E:3BC1`
- Reads ROM: `$C4:5F97`; `$C4:5FC5`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$28`, `+$2A`, `+$2E`, `+$30`
- Opcode table entry: `$8C:E9F9` (0x9e)
