Caster entity, spell, level, then a 0-terminated list of target entities (an entry equal to `$3BC1` is skipped). Spells 2 and `$16` allocate a slot per target (`$91:9777`); the spell's routine comes from `$C4:5F97` / `$C4:5FC5` (`$91:973E`, `$91:AD17`). Without a free slot it reads three more expressions and the list from where it stands: the same end only for lists of three or more.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:C521`; `$91:973E`; `$91:9759`; `$91:9777`; `$91:AD17`
- Reads WRAM: `$7E:3BC1`
- Writes WRAM: `$7E:3BC1`
- Reads ROM: `$C4:5F97`; `$C4:5FC5`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$28`, `+$2A`, `+$2E`, `+$30`
- Opcode table entry: `$8C:E9F9` (0x9e)
