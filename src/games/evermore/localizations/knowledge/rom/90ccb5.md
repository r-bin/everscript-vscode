Dims all field entities and uploads the background menu palette when opening full-screen menus. Uploads 8 colors from `$A8EB` via `$90:CFB8`, sweeps across all 16 enemy entity records (`$7E:3DE5..$7E:4E89`), setting active palette attribute `+$0C,Y = 8` for all active entities, and resets palette cache flags `$1288..$128C`.
