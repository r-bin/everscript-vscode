The address of each alchemy formula's block in bank `$91` (34 blocks; 35 formulas, Acid Rain and
Laser share one). A block is a small record (0x14 to 0x80 bytes, back to back) that describes
the cast; among its words are the animation records the spell shows, e.g. Acid Rain's block
`$91:86F0` names record `$583E`. These are the same values the everscript enums call
`ALCHEMY_TYPE_ANIMATION.*` / `ALCHEMY_TYPE_PROJECTILE.*`, and what an alchemy slot keeps at
`+0x12` (enum `ALCHEMY_ANIMATION.TYPE`).

Where multiple animation record IDs are stored (at offsets `+4..+28`), they represent sequential
visual phases (e.g. Part A charge/projectile, Part B impact/burst). Native 65816 ASM in Bank `$91`
coordinates transitions between them when opcode `0x5D` (`effect_done`) sets entity `+0x26 bit 1`.

## Notes
- The fields of a block are not decoded. The Scripts tab finds the records by scanning the
  block's words for record ids, so a word that happens to equal a record id would be listed too.
- 33 animation records signal `effect_done` (animation command `0x5D`, which only bank `$91`
  reads); all lie in `$C4:571A..$C4:589E`. Most records the blocks name are among them.
- Fireball's enum value (`$8C86`) disagrees with this table (`$8CB6`); the table is what the ROM holds.
