Activates the walking animation action track for the entity currently bound to Direct Page register `$4C`:
- Retrieves the entity's master archetype record index from slot field `+$60,Y` into register `X`.
- Evaluates the entity's current activity/movement flag word at `+$64,Y`. If zero, delegates to idle track handler `$90:8293`.
- For active movement, reads the 16-bit walking animation sequence descriptor pointer from character record field `+$34` in Bank `$8E` (`$8E:0034,X`).
- Transfers the resolved track pointer to register `X` and jumps directly to the animation VM sequence loader `anim_start_record` (`$90:8124`), initializing script execution registers for the new gait.
- Invoked across player control loops, companion AI follow behaviors, and roaming enemy navigation routines.
