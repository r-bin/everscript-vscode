Core engine 16-bit fixed-point trigonometric scaling utility. Takes angular phase in DP $06
and 16-bit scaling multiplier in Accumulator A. Computes sine projection across low and high byte
components via `$80:ACF5`, combines products into 32-bit fixed-point registers DP $02..$04, and returns
scaled sinusoidal displacement in DP $03 (integer) / DP $02 (fractional).
Full disassembly and clean C reconstruction: `docs/disassembly/maps/heat-shimmer.md`.
