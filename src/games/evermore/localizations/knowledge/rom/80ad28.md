Core engine 16-bit scaling utility. Takes a 16-bit value in DP $06 and a 16-bit multiplier in
Accumulator A. It also uses the incoming high byte of DP $01 in its final low-word addition.
It calls `$80:ACF5` for each multiplier byte and combines the overlapping partial-product words
into DP $02..$04. It returns DP $02 in A; the heat-shimmer caller ignores A and reads DP $03,
which overlaps the high byte of DP $02 and low byte of DP $04. The routine itself contains no
sine-table lookup. Full disassembly and C reconstruction: `docs/disassembly/maps/heat-shimmer.md`.
