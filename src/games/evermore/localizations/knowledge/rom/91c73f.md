# spell_barrier_shield_state_machine_dispatcher

State machine dispatcher for active Barrier and Defend magical shield effects.

## Metadata
- **Address:** `$91:C73F`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 182 bytes

## Functionality
Controls the active lifecycle of protective magical barriers (such as the Barrier spell).
The routine checks barrier status in `$7E:23B5`, branching to state handlers that absorb incoming damage procs, test terrain collision via `$91:C899`, and decrement remaining shield duration before collapsing the barrier.
