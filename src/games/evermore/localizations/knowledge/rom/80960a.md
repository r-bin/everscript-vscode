# oam_depth_sorted_sprite_insert_node

Inserts sprite render records into a Y-depth sorted linked list for proper hardware OAM layering.

## Metadata
- **Address:** `$80:960A`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 123 bytes

## Functionality
Maintains depth-sorted sprite rendering order across all visible actors and particles.
The routine traverses the active sprite queue starting at `$50AD,X`, comparing vertical screen coordinate `$04,Y` of incoming sprite `$1276`.

It inserts the sprite into the proper ascending Y position in the linked list, ensuring foreground entities and shadows are rendered in correct visual layering without z-fighting artifacts.

## Callers
- `$8F:C6C5` (`sprite_sorting_canopy_occlusion_and_render_depth`)
- `$90:81F0` (`FUN_9081f0`)
- `$90:DB9E` (`entity_shadow_oam_sprite_render`)

## Callees
- None

## Variables and Memory
- `$1276` (Active sprite record pointer to be inserted)
- `$50AD` (Head array of depth-sorted sprite bucket linked lists)
- `$04,Y` (Sprite Y screen coordinate used as sorting key)
