Core routine applying a beneficial buff or harmful ailment to an entity:
- Scans the 4 entity status slots (`+$46`, `+$4C`, `+$52`, `+$58`).
- Refreshes matching active status duration if already present.
- Allocates first empty slot (`$FFFF`).
- If full, evicts oldest non-recent buff. The vanilla code at `$91:B7FA` famously misidentified the slot ID, causing the permanent 5-status buff stacking bug.
