The one place the game reads a character record's `+$00`: it takes an entity, follows its `+$60` to the
record in bank `$8E`, and copies the record's 24-bit name pointer to `$22`–`$24` for the text routines
`$8C:AF2B` and `$8C:9E03`. The routine seems to start at `$8C:89F6`, but where it is called from has not been traced.
The host reads the same field as `entityNamePointer` (`maps/character-record.ts`), and the emulator page
uses it to label entities.
