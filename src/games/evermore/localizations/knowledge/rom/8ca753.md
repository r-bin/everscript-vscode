Streams newly rasterized dialogue window glyph tiles from Bank `$7F` into SNES VRAM:
- Configures DMA channel 1 source address to `$7FA0` in Bank `$7F`.
- Sets destination VRAM word address into `DP $2E`.
- Determines tile transfer byte count based on character height in tiles.
- Calls `$80:8650` (`vram_dma_upload_tile_block`) to initiate the DMA transfer.
- Updates cursor position by looking up character width in table `$C4:0C02`.
