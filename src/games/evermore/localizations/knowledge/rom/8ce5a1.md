Evaluates an entity expression and compares it with `$0F42`, the entity currently followed by the camera. If they differ, calls `$8C:F1A7`, which toggles `$0F42` between the Boy and Dog records and transfers active-character state. If they match, the helper is skipped. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:F1A7`
- Reads WRAM: `$7E:0F42` Entity the camera follows
- Opcode table entry: `$8C:E9ED` (0x98)
