NMI exit sequence and user VBLANK callback dispatcher:
- Invokes far hook vector `$7E:0125` using indirect JML (`JML [$0125]`) with return address `$80:84C0` pushed onto stack via `PEA`.
- On callback return, sets 16-bit accumulator/index registers (`REP #$30`).
- Restores direct page (`PLD`), Y register (`PLY`), X register (`PLX`), Accumulator (`PLA`), and Data Bank (`PLB`).
- Executes `RTI` to resume interrupted gameplay thread execution.
