Low-level synchronous byte transfer loop for SPC700 block uploads.
Transmits each byte by packing an 8-bit counter into port `$2140` and the payload byte into port `$2141`
using a single 16-bit write (`STA $2140`), waits for the SPC700 to echo the counter back on port `$2140`,
handles 32KB bank boundary rollover (`$8000`), and spaces successive blocks by adding 4 to the counter.
Full disassembly and clean C reconstruction: `docs/disassembly/audio/spc-block-uploader.md`.
