Multi-stage aggro detection pipeline:
1. Stamina Gate: aborts immediately if entity stamina `+0x2E` is below `0x0400` (100%).
2. RNG Roll: requires `rand(0..255) < aggro_chance` (`character +0x15`).
3. Proximity Check (`$8F:D6CE`): tests Boy (`$0F3E`) and Dog (`$0F40`) for HP > 0 and distance within `aggro_range` (`character +0x13`).
4. On match: writes target pointer into `entity +0x24`, faces target (`$80:ADF0`), and sets alert state `+0x78`.
