Updates an entity's current elevation plane (bits 5..4) when walking onto standard metatiles.
Preserves the entity's existing plane when traversing always-walkable tiles (bit 13, e.g. conveyor/slide)
or plane-transparent tiles (bit 6, e.g. underpasses/bridges). Writes new plane to DP `$44` and entity
record field `+0x18`.
Full disassembly and clean C reconstruction: `docs/disassembly/maps/tile-collision.md`.
