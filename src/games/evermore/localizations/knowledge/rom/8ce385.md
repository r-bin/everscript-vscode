Script opcode 0x8D starts a screen shake when its byte operand is nonzero. A zero operand skips the call and does not stop or otherwise modify shake state. The handler returns Carry Set to continue in either case.

Previously believed: operand zero called `$90:988E` to stop shaking. The handler listing at `$8C:E385` shows no such call; only the nonzero path calls `$90:9897`.

Returns Carry Set (`SEC`) to continue executing instructions in the same turn.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$90:9897` Start a screen shake (magnitude 4 both axes)
- Opcode table entry: `$8C:E9D7` (0x8d)
