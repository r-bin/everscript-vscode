Script opcode 0x8D controls ambient screen tremors and camera jitter:
- Operand `0`: Invokes `screen_shake_stop` (`$90:988E`), clearing shake active flag `$C3` and offsets `$C5`/`$C7`.
- Operand `!= 0`: Invokes `screen_shake_start` (`$90:9897`), setting `$C3 = 1` and magnitudes `$7E:2409 = 4`, `$7E:240B = 4`.

Returns Carry Set (`SEC`) to continue executing instructions in the same turn.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$90:988E`; `$90:9897` Start a screen shake (magnitude 4 both axes)
- Opcode table entry: `$8C:E9D7` (0x8d)
