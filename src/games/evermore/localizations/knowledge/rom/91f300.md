Master dictionary and substitution tables for dialogue string compression in Bank `$91`:
- `$91:F32E`: Digraph table (32 frequent English character pairs, 64 bytes).
- `$91:F3AE`: Single character mapping table (64 bytes).
- `$91:F3EC`: Secondary word pointer table (64 words = 128 bytes, indexed by token `(byte << 1) & 0x7E`).
- `$91:F46C`: Primary word pointer table (256 words = 512 bytes, indexed by token `index * 2`).
- `$91:F66C`: Secondary dictionary word storage (NUL-terminated strings).
- `$91:F7D5`: Primary dictionary word storage (NUL-terminated strings).
Used by `dialogue_string_dictionary_expand` (`$8C:CD84`) to unpack dialogue keys into `$7F:D81E`.
