Blits a 2-byte tile cell to the dialogue window tilemap in VRAM. Calculates VRAM address from window position `+$14,Y` and line offsets, writes tile word `$27E8` into buffer `$7F:C800,X`, and uploads 2 bytes via DMA to VRAM `$0800` via `vram_dma_upload_tile_block` (`$80:8650`).
