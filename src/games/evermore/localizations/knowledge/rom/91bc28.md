Dispatches active status effect timer countdowns and per-frame logic:
- Increments frame counter `$0FB2`.
- Masks out recency flag (bit 15).
- Dispatches execution via status jump table `$91:AE31,X` (Atlas, Barrier, Defend, Reflect, Speed, etc.).
- Invokes cleanup handler and prints wear-off message when timers expire.
