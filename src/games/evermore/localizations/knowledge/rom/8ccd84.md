Core string decompression engine for dialogue and descriptive text in Secret of Evermore:
- Invoked via `JSL $8CCD84` from `decode_dialogue_string_key` (`$8C:CD24`).
- Reads token stream from Direct Page 24-bit pointer `[$22]` and emits decoded ASCII characters into Bank `$7F` text buffer (starting at `$7F:D81E` indexed by `Y`).
- Implements a 5-tier compressed format:
  1. `0x00..0x3F`: Single character table lookup (`$91:F3AE`).
  2. `0x40..0x7F`: Literal run of $(N = \text{byte} \ \& \ 0x3F)$ uncompressed bytes.
  3. `0x80..0xBF`: Digraph pair lookup (`$91:F32E`).
  4. `0xC1..0xFF`: Secondary word dictionary lookup (`$91:F3EC` offset into `$91:F66C`).
  5. `0xC0`: Primary 256-word dictionary lookup with subsequent index byte (`$91:F46C` offset into `$91:F7D5`).
- Terminates upon encountering `0x00` in single chars, literal runs, or digraphs.
