Core 4-tier text decompression engine for Secret of Evermore script and dialog text.
Evaluates compressed token byte prefixes:
- `0x00..0x3F`: Single decoded character from `$91:F3AE`.
- `0x40..0x7F`: Raw literal character run of length `token & 0x3F`.
- `0x80..0xBF`: Dual Tile Encoding (DTE) 2-character digram from `$91:F32E`.
- `0xC2..0xFE`: Multi-Tile Encoding (MTE) word string from `$91:F66C` via table `$91:F3AE+0x3E`.
- `0xC0`: Extended Dictionary phrase expansion indexed by trailing byte via `$91:F46C` from `$91:F7D5`.
Emits decompressed characters into target WRAM buffer until null terminator.
