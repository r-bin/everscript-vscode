Stamps a replacement metatile ID into the live WRAM field map grid at `$7F:0000,X` and queues tilemap pattern updates to the VRAM DMA staging ring buffer at `$7E:1174` / `$7E:11F4` for visible Layer 1 and Layer 2 tiles.

### Mechanics:
1. Loads the old metatile ID from `$7F:0000,X` (where X is the destination grid byte offset from `$04`) and reads its old Layer 1 (`$12`) and Layer 2 (`$14`) VRAM tile words from the metatile definition table in `$7F:0000`.
2. Stamps the replacement metatile ID from `$02` into `$7F:0000,X`.
3. Compares the new Layer 1 tile against old Layer 1 tile `$12`. If changed and within Layer 1 screen bounds (`$0F90`..`$0F92`, `$0F8C`..`$0F8E`), computes target screen offset `((Y & 0x1F) << 5) | (X & 0x1F)` and stages tile word into ring buffer at `$7E:1174,Y` / `$7E:11F4,Y`.
4. Compares new Layer 2 tile against old Layer 2 tile `$14`. If changed and within Layer 2 screen bounds (`$0F98`..`$0F9A`, `$0F94`..`$0F96`), sets bit 10 (`0x0400`) for Layer 2 base screen offset and commits to the staging buffer.
5. Advances staging cursor `$7E:1170` by 2 bytes (wrapping at `0x0080` = 128 bytes = 64 entries).
