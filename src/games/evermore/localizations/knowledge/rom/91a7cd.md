# spell_projectile_collision_radius_and_bounds_test

Tests spell projectile contact radii against room boundaries and target entity bounds.

## Metadata
- **Address:** `$91:A7CD`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 116 bytes

## Functionality
Performs boundary and hitbox proximity validation for active spell projectiles.
The routine evaluates projectile spatial coordinates, testing against room outer margins and active monster collision boxes.

If outside valid bounds, it terminates projectile motion; if intersecting a valid target, it advances to damage impact staging.

- Spell collision dispatchers in Bank `$91`

- None

- `$14,Y` (Projectile collision check sequence counter)
- `$18,Y`, `$1A,Y` (Projectile boundary limit thresholds)
