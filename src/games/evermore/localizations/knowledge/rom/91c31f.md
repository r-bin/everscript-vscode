# hdma_gradient_channel_5_table_upload

Builds vertical HDMA screen gradient tables and arms SNES DMA Channel 5 for lighting effects.

## Metadata
- **Address:** `$91:C31F`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 133 bytes

## Functionality
Configures SNES hardware HDMA Channel 5 to produce vertical raster color gradient illumination effects.
The routine builds a scanline brightness table in WRAM Bank `$7F` (`$D707..$D70B`), sets HDMA mode `#$42` in `$4350`, and configures DMA Channel 5 table address registers (`$4352`) to run during active display.

## Callers
- `$91:C2C0` (`func_91C2C0`)

## Callees
- None

## Variables and Memory
- `$7F:D707..$7F:D70D` (HDMA scanline brightness and color table)
- `$4350` (SNES DMA Channel 5 parameters register)
- `$4352` (SNES DMA Channel 5 table address register)
