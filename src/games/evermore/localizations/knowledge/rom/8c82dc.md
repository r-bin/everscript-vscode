- Stores sound effect ID in parameter register `$0E4F`.
- Forwards execution to `$8C:831D` to issue command byte `0x04` across hardware port `$2140`.
- Used by script sound opcodes `0x30`, `0x31`, `0x32` and character animation sound triggers.
