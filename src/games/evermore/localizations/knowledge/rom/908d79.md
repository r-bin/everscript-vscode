# sprite_oam_perspective_scaling_and_draw

Scales sprite dimensions and position by depth perspective ratios before drawing to OAM.

## Metadata
- **Address:** `$90:8D79`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 144 bytes

## Functionality
Projects entity and particle sprites according to depth and distance scaling factors.
The routine loads depth ratio `$10,Y`, computes perspective scaling factors via hardware division registers `$4204`/`$4206`, adjusts relative horizontal and vertical displacements (`$14,Y`, `$16,Y`), and emits scaled sprite entries into the OAM buffer via `$80:9033` (`direct_sprite_draw_oam`).

## Callers
- Particle and spell draw dispatchers in Bank `$90`

## Callees
- `$80:9033` (`direct_sprite_draw_oam`)

## Variables and Memory
- `$10,Y` (Depth and distance perspective scale parameter)
- `$12,Y` (Perspective scaling factor divisor)
- `$14,Y`, `$16,Y` (Screen space position coordinates)
