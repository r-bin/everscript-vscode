Determines if an entity's world coordinates (`$46`, `$48`) are within the camera's visible screen
frustum bounding box defined by `$7E:0F48` (left), `$7E:0F4A` (top), `$7E:0F4C` (right), and `$7E:0F4E` (bottom).
Returns **Carry Set** if the entity is visible, or **Carry Clear** if it is outside the viewport and should be culled.
