Allocates a CGRAM palette slot for alchemy visual effects. Advances bytecode script offset `+$14,Y` by 4 bytes and retrieves palette index from `$91:0002,X`. For high entity indices (`+$2E,Y >= $4E89`), commits palette to hardware slots `$0C` or `$0E` via `load_sprite_palette` (`$90:CF3A`); otherwise borrows slot 4 via `palette_steal_slot_4` (`$90:CE92`). Links slot via `func_90CE15`.
