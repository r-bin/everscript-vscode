Uploads dynamic sprite tile patterns to VRAM and synchronizes active palette attributes across all active entities. Copies sprite tile staging buffer from `$7E:6289` to VRAM via `$80:85FA`, then loops through all 16 enemy/NPC entity slots (`$7E:3DE5..$7E:4E89`, 142-byte stride), extracting bits 1..3 (`AND #$000E`) from base palette field `+$74,X` and writing into active palette attribute `+$0C,X`.
