Master font bitmap data table stored in Bank `$C4` for the in-game dialogue window and menu text system:
- Contains glyph bitmaps for 201+ character codes.
- Characters are indexed with offset `(char_code - 0x20)`.
- Each character glyph consists of 8 to 12 row slices, read row-by-row by the rasterizer `$8C:A5AC`.
- Used in combination with proportional width table `$C4:0C02`.
- Full clean C decompilation: `docs/disassembly/ui/dialogue-glyphs.md`.
