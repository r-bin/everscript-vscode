Handler of script opcode [0x6E](soe://rom/assets/scripts/opcodes/6e.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/6e.md`, served at `soe://rom/assets/scripts/opcodes/6e.md`.

Sets DP `$12 = 1`, then uses the shared entity/tile-coordinate decoder (unsigned tile bytes scaled by eight) and `$8C:DAA6` dead-entity guard. The nonzero mode dispatches to `$8F:AAD3` for direct movement rather than terrain-aware `$8F:AA82`; direct movement sets flags `$0230`. Host-side model: `docs/disassembly/script-vm/opcode-6e-walk-to-tile-direct.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
- Opcode table entry: `$8C:E999` (0x6e)
