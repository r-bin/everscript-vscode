Evaluates an entity, reads tile X and Y bytes, and scales them by 8 into DP `$46`/`$48`. It selects the shared helper's skip mode, so the common continuation does not call `$8F:AA82` to submit the position. No entity-field write is made in the opcode path; the purpose of staging these scratch values without the helper is unresolved. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
- Opcode table entry: `$8C:E999` (0x6e)
