128-byte proportional font character width table stored in Bank `$C4`:
- Indexed directly by ASCII character code (e.g. `'A'`–`'J'` have widths `6, 6, 5, 6, 6, 5, 6, 6, 2, 5`).
- Read by the dialogue glyph streaming routine (`$8C:A753`) to advance the window cursor X position after rendering each character.
- Paired with secondary font table `$C4:1884` for narrow/bold font variants.
- Full clean C decompilation: `docs/disassembly/ui/dialogue-glyphs.md`.
