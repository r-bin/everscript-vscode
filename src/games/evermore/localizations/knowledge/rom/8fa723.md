Checks spatial distance between the companion and the leader entity.
If within $\pm 2$ pixels in both horizontal and vertical axes, flags arrival mode
by setting bits 4 and 5 in `$7E:3C12,X` (`|= 0x0030`). If farther, clears arrival bit
to continue breadcrumb pathfinding.
Full disassembly and clean C reconstruction: `docs/disassembly/entities/companion-navigation.md`.
