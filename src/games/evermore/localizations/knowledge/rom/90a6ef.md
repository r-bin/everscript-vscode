Drains up to 4 pending grass cutting animation slots per frame from the 24-slot FIFO queue at `$7E:0FD2`–`$7E:1001`.

### Mechanics:
1. Reads round-robin queue cursor from `$7E:0FD0` and processes 4 slots (`$42 = 4`).
2. For each active slot (`$7E:0FD2,X != 0`), reads the next metatile word from the room sequence in ROM (`[$8B],Y`).
3. If word is `0x0000` (terminator), frees slot (`STZ $0FD2,X`).
4. If valid metatile ID, advances sequence cursor `Y += 2`, reads destination grid offset from `$7E:1002,X` and packed tile coordinates `(X, Y)` from `$7E:1032,X`, then calls `cuttable_grass_apply_metatile_mutation` (`$90:A739`).
5. After batch, advances `$7E:0FD0` by `X` (wrapping at `0x0030` = 48 bytes = 24 slots), completing 1 keyframe every 6 frames (~100 ms).
