# save_menu_yes_no_cursor_highlight_draw

Renders the flashing selection cursor over Yes or No options in the Save Menu confirmation prompt.

## Metadata
- **Address:** `$8D:E020`
- **Type:** `routine`
- **Bank:** `$8D`
- **Size:** 87 bytes

## Functionality
Draws the highlight cursor sprite for binary confirmation prompts (e.g. Save Game: Yes/No, Overwrite: Yes/No).
The routine checks the active prompt selection state in `$0D0D`. It loads corresponding screen coordinates (`$04 = #$9A` or `#$A6`), and calls `$80:9033` (`direct_sprite_draw_oam`) to display the animated cursor sprite next to the chosen option.

## Callers
- `$8D:DF07` (`save_menu_yes_no_confirmation_prompt`)

## Callees
- `$80:9033` (`direct_sprite_draw_oam`)

## Variables and Memory
- `$0D0D` (Active confirmation prompt choice index: 0 = Yes, 1 = No)
- `$26`, `$27` (Cursor sprite tile attributes)
- `$02`, `$04` (Cursor screen space coordinates)
