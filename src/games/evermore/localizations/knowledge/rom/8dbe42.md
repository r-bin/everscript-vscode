# ring_menu_item_icon_graphic_and_palette_setup

Loads 16x16 icon graphics and color palettes for ring menu items from ROM master tables.

## Metadata
- **Address:** `$8D:BE42`
- **Type:** `routine`
- **Bank:** `$8D`
- **Size:** 134 bytes

## Functionality
Sets up graphical icons for items, weapons, and alchemy formulas displayed in ring menus.
The routine loads the item index from `$0D1D,X`, indexes ROM master icon lookup tables at `$C4:601F` and `$C4:5CC7`, and loads the 16x16 tile patterns and palette indices into UI VRAM buffers via `$8C:A4A1`.

## Callers
- `$8D:BA2F` (`func_8DBA2F`)

## Callees
- `$8C:A4A1` (`func_8CA4A1`)

## Variables and Memory
- `$0D17` (Active ring menu slot offset)
- `$0D1D,X` (Item ID assigned to ring menu slot)
- `$C4:601F` (ROM table of icon graphic indices)
- `$C4:5CC7` (ROM table of icon palette descriptors)
