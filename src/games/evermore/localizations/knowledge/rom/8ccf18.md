Takes a free script slot and points it at the script whose packed pointer is in DP `$26`-`$28`, with its
local bytes and fields cleared. This is where a packed pointer becomes a bus address: bank
`$92 + (p >> 15)`, address `$8000 | (p & $7FFF)`. Callers then link the slot (a call stores the caller in
+`$0B` and pushes the new slot on the run list; a start queues it with `$8C:CE86`).
