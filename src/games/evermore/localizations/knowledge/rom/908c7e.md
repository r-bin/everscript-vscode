# sprite_direct_tile_slot_render_oam

Renders 16x16 sprite tile entries directly into the hardware OAM buffer from indirect asset pointers.

## Metadata
- **Address:** `$90:8C7E`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 112 bytes

## Functionality
Low-level sprite drawer for UI icons, indicators, and small particles.
The routine unpacks tile index and palette attributes from indirect pointer `[$5D]`, loads screen coordinates `$02` (X: `$16`) and `$04` (Y: `$5C`), and emits hardware OAM entries via `$80:9033` (`direct_sprite_draw_oam`).

## Callers
- Direct sprite particle rendering loops in Bank `$90`

## Callees
- `$80:9033` (`direct_sprite_draw_oam`)

## Variables and Memory
- `$5D` (Indirect pointer to sprite tile record)
- `$26`, `$27` (OAM tile attribute staging words)
- `$02`, `$04` (Screen space position coordinates)
