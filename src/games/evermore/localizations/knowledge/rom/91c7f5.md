# spell_barrier_collision_box_clear_and_init

Clears spatial collision buffers and initializes coordinate boundary masks for active barrier spells.

## Metadata
- **Address:** `$91:C7F5`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 164 bytes

## Functionality
Initializes the barrier spatial hit grid and boundary masks when casting Barrier or Defend spells.
The routine resets the 512-byte barrier spatial collision buffer in WRAM at `$7E:6869..$7E:6A7D`, initializes collision state flags in `$157C`, and configures barrier width and coordinate stride offsets for subsequent terrain barrier raycasting via `$91:C899`.

## Callers
- `$91:C73F` (`spell_barrier_shield_state_machine_dispatcher`)

## Callees
- `$91:C899` (`collision_tilemap_spatial_raycast_and_barrier_test`)

## Variables and Memory
- `$157C` (Active barrier collision state enable flag)
- `$156C` (Barrier boundary diameter scalar)
- `$7E:6869..$7E:6A7D` (Barrier spatial footprint buffer, 512 bytes)
