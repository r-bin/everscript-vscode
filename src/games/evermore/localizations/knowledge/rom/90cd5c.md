Requests a dynamic sprite palette slot allocation and binds it to an entity record (`$4C`). Initializes palette reservation state `$0404` in entity field `+$74,Y`, invokes `Sprite_palette_allocator_90CD80` (`$90:CD80`), and commits the assigned palette index to entity active palette `+$0C,Y`, base palette `+$74,Y`, and saved palette `+$75,Y`.
