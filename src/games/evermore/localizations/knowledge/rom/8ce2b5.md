Scans the byte slots beginning at `$0B95` until it finds a negative-byte sentinel, then evaluates two expressions. The first value selects range bits in `$0E6C`; a byte from `$8C:E311` is written at the selected `$0B95` slot and `$0B96` is set to `$FF`. The second value is written to `$0BC5` at twice the selected slot index. The meaning of the ranges and fields is not established. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Reads WRAM: `$7E:0B95`; `$7E:0E6C`
- Writes WRAM: `$7E:0B95`; `$7E:0B96`; `$7E:0BC5`; `$7E:0E6C`
- Reads ROM: `$8C:E311`
- Opcode table entry: `$8C:E9CF` (0x89)
