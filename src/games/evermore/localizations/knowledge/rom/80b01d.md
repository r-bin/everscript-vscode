# math_fixed_point_sin_cos_multiply

Computes fixed-point sine and cosine projections using hardware multiplier registers.

## Metadata
- **Address:** `$80:B01D`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 300 bytes

## Functionality
Performs fixed-point trigonometry calculations using the SNES hardware multiplication registers.
Given an angle index in the Accumulator (0..255) and an amplitude scalar in `$06`, the routine indexes sine/cosine lookup tables at `$80:88A3`.

It writes operands to hardware multiplier registers at `$4202`, waits for the calculation cycle, and reads the 16-bit signed product from `$4216`, returning projected vector coordinates in `$04` and `$02`.

## Callers
- `$90:DE11` (`FUN_90de11`)
- `$91:A3F0` (`spell_projectile_3d_spatial_vector_step`)

## Callees
- None

## Variables and Memory
- `$80:88A3` (ROM 256-entry fixed-point sine/cosine table)
- `$4202` (Hardware multiplier multiplicand register)
- `$4216` (Hardware multiplier 16-bit product register)
- `$02`, `$04` (Resultant X and Y vector projection outputs)
