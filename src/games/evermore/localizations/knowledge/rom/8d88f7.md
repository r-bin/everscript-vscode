# status_menu_player_name_and_portrait_formatter

Formats player character name strings and portrait tile references into the Status Menu header bar.

## Metadata
- **Address:** `$8D:88F7`
- **Type:** `routine`
- **Bank:** `$8D`
- **Size:** 116 bytes

## Functionality
Populates character identification headers on the Status Menu page.
The routine checks selected character index (Boy vs Dog), retrieves the hero\'s custom name string from save memory, and calls `$80:B149` (string copy) to write the name into the menu tilemap buffer.

It also loads character portrait tile references and palette selectors into the status window header.

## Callers
- `$8D:87DA` (`func_8D87DA`)

## Callees
- `$80:B149` (`func_80B149`)

## Variables and Memory
- `$7E:22DB` (Active selected party member index)
- `$7E:22D3` (Protagonist name string storage buffer, 8 characters)
