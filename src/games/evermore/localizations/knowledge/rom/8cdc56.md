Handler of script opcode [0x91](soe://rom/assets/scripts/opcodes/91.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/91.md`, served at `soe://rom/assets/scripts/opcodes/91.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$80:85D8`; `$90:94AB` Camera: centre on the target and clamp to the map bounds
- Reads WRAM: `$7E:0105` in Joypad 1 buttons newly pressed this frame (+$1)
- Writes WRAM: `$7E:0106` PPU register shadows, copied to the PPU every NMI
- Opcode table entry: `$8C:E9DF` (0x91)

## Notes
Previously believed: hypothesized in earlier notes to be a joypad button filter register. `$7E:0106` is
the PPU register shadow for `$2100` (`INIDISP`), copied to hardware on every NMI.
