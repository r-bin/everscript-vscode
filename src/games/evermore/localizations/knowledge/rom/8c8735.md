Finds next valid target candidate in active entity list. Asserts search bit `$0100` in `$05AD`. If incoming Y is zero, starts at head `$3DDF`; otherwise advances to `+$5E,Y`. Filters each entity with `target_candidate_filter` (`$8C:8658`). If candidate found, stores into `$0,X`, clears `$2,X`, and returns with carry clear; returns carry set if end of list reached.
