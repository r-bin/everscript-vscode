The only script wait whose length the engine decides: a walk finishing, a text box closing, the
camera coming to rest. When nothing is pending it is a plain one-tick yield. The simulation
treats each one as an event at an unknown tick (at least one tick later) and records any order
it has to assume (`src/games/evermore/simulation/time.ts`).

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Reads WRAM: `$7E:0FAE`; `$7E:2429` Active step-on trigger script ID; `$7E:3C18`
- Writes WRAM: `$7E:3C1A`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$03`, `+$05`, `+$06`, `+$10`, `+$6C`, `+$88`, `+$8A`
- Opcode table entry: `$8C:E919` (0x2e)
