# mode7_camera_altitude_matrix_parameters_set

Calculates and stores Mode 7 altitude scaling and camera tilt parameters in flight registers.

## Metadata
- **Address:** `$80:C308`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 86 bytes

## Functionality
Stores vertical scaling parameters for Mode 7 camera altitude transitions.
The routine reads altitude scalar `$0E72` and pitch angle `$0E76`, performing bitwise shifts to compute altitude parameters in `$14AC` and `$14AE`, ensuring proper horizon perspective and terrain scaling.

## Callers
- `$80:C35E` (`mode7_camera_altitude_zoom_perspective_calc`)

## Callees
- None

## Variables and Memory
- `$0E72` (Mode 7 camera focal altitude)
- `$0E76` (Mode 7 vertical pitch angle)
- `$14AC`, `$14AE` (Mode 7 altitude transformation words)
