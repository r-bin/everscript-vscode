Evaluates an entity and an amount. If the entity's HP field at `+$2A` is nonzero, adds the amount to pending damage at `+$76` and sets state bit `$0008` at `+$12`; otherwise it leaves the entity unchanged. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:C132`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$2A`
- Opcode table entry: `$8C:E9E3` (0x93)
