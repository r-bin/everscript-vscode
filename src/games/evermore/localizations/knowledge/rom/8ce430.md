Damage with a hit reaction. Reads and clears the one-shot `$23D5`: when it was set, the instruction runs as opcode `0xBB` instead (same operands; damage without knockback, Everscript `NEXT_DAMAGE_NO_KNOCKBACK`). Otherwise: entity and amount; skips an entity with 0 HP or `+$10` bit `$1000`; when the one-shot `$23D7` is set (and cleared) `$8F:C06D` transforms the amount; `$8F:C121` queues it as pending damage (`+$76`, `+$12` |= `$0038`). Returns Carry Set.

Previously believed: a set `$23D5` skipped the damage.
