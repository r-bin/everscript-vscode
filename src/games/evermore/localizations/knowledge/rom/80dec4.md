# mode7_flight_compass_needle_smooth_tracking_step

Interpolates compass rose needle heading smoothly towards aircraft yaw during Mode 7 flight.

## Metadata
- **Address:** `$80:DEC4`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 123 bytes

## Functionality
Smooths compass needle rotation in the Mode 7 cockpit HUD.
Rather than snapping abruptly when the aircraft turns, the routine compares current target yaw angle `$BB` (adjusted by offset `#$40`) against displayed needle heading `$14BC`.

It increments or decrements needle angle `$14BC` by single-step deltas towards convergence, producing smooth analog compass needle movement.

## Callers
- `$80:C1A2` (`FUN_80c1a2`)
- `$80:C95B` (`FUN_80c95b`)

## Callees
- None

## Variables and Memory
- `$BB` (Current aircraft heading orientation angle)
- `$14BC` (Current displayed compass rose needle angle in HUD)
- `$14BA`, `$14B4` (Turn acceleration tracking variables)
