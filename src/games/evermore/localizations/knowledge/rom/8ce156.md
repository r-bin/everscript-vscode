Handler of script opcode [0x79](soe://rom/assets/scripts/opcodes/79.md). Calls opcode `$8C:E0B0`, then checks entity `+$88`; if no waiter is set, registers the current script slot there, sets slot `+$03 = 6`, entity `+$8A = $20`, slot `+$05 = $20`, and slot `+$09 = 0`. Both paths return carry clear to yield. Host-side model: `docs/disassembly/script-vm/opcode-79-animate-and-wait.md`.
