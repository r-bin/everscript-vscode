# mode7_compass_and_horizon_hud_sprite_render

Renders the Mode 7 flight HUD compass rose, directional needle, and artificial horizon pitch indicator.

## Metadata
- **Address:** `$80:D23A`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 718 bytes

## Functionality
Calculates on-screen sprite coordinates and angles for the Mode 7 flight cockpit instruments.
The routine queries the current aircraft yaw heading at `$14C6` and pitch/altitude at `$14B8`.

It indexes trigonometry offset tables at `$80:F2AF` and `$80:F2B1` to project the rotating compass needle and horizon line across the flight viewport. It formats sprite coordinates and tile references into the OAM buffer at `$ACBF`, updating cockpit telemetry every frame.

## Callers
- `$80:D22D` (`func_80D22D`)

## Callees
- None

## Variables and Memory
- `$14B8` (Mode 7 flight altitude / vertical camera tilt angle)
- `$14C6` (Mode 7 aircraft yaw heading angle)
- `$80:F2AF..$80:F2B1` (Trigonometric projection table for HUD compass)
- `$ACBF` (OAM sprite staging buffer for flight instruments)
