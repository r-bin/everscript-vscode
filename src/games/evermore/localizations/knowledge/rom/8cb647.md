Blits an arbitrary rectangular 9-slice window frame into shadow tilemap RAM at `$7F:C800`:
- Computes tilemap row offsets using SNES hardware multiplier registers `$4202` / `$4216` ($Y \times 32$ tiles).
- Writes top-left corner (`0x0BF0`), top horizontal edges (`0x0BF1`), and top-right corner (`0x0BF2`).
- Renders vertical left (`0x0BF3`) and right (`0x0BF4`) border edges for intermediate scanline rows.
- Writes bottom-left corner (`0x0BF5`), bottom horizontal edges (`0x0BF6`), and bottom-right corner (`0x0BF7`).
