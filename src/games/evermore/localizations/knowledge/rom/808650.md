Executes a DMA channel 1 transfer to write a block of graphical tile data directly into VRAM:
- Checks controller / screen flag `$0106` bit 7.
- Increments VRAM access lock counter `$7E:0F3A` to prevent race conditions during VBLANK.
- Configures PPU registers:
  - `$2115` (`VMAIN`): sets word increment mode (`0x80`).
  - `$2116` (`VMADD`): sets target VRAM base address from `DP $2E`.
- Programs DMA channel 1 registers:
  - `$4310` (`DMAP1` / `BBAD1`): set to `$1801` (word increment write to `$2118` `VMDATA`).
  - `$4312` (`A1T1`): source byte address from `DP $26`.
  - `$4314` (`A1B1`): source bank byte from `DP $28`.
  - `$4315` (`DAS1`): transfer length in bytes from register X.
- Triggers DMA transfer by asserting bit 1 (`0x02`) in hardware register `$420B` (`MDMAEN`).
- Decrements VRAM lock counter `$7E:0F3A` upon transfer completion.
