Traverses the active entity linked list starting at `$3DDF` (following next pointer `+$5E,Y`) to find the first valid targeting candidate. Sets flag bit `$0100` in `$05AD`, filters each entity with `target_candidate_filter` (`$8C:8658`), and if valid, saves target pointer into `$0,X` and returns with carry clear; returns carry set if no target satisfies candidate criteria.
