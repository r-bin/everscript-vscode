Clears bit 15 of `$0B2B`; when anything else is left there, it rebuilds the default text window
(record `$034D`, window 0 in `$8C:D967`'s numbering) with fixed layout values, points it at the
pending text (`$0DFB`/`$0DFC`, indexed by `$0B2F`) and shows it through `$8C:9E03`. The script
opcodes that call it touch the text box, which is why the simulation treats them as global
(`simulation/reach.ts`). What the record fields mean is not traced yet.
