Clears pause bit 15 of `$0B2B`. If a dialogue request is pending, it pops the next 24-bit script
instruction pointer from circular queue `$7E:0DFB,x` (indexed by tail `$0B2F`) into DP `$22`–`$23`.
It initializes the primary text window record at `$7E:034D` to 20 columns by 30 rows, palette index 2,
glyph delay 16, and border tile `$1924`. It calls `$8C:AC8A` to assemble the frame, sets bit 4 of
`$7E:035F` to mark the window active, and dispatches the streaming text renderer at `$8C:9E03`.
Full disassembly and clean C reconstruction: `docs/disassembly/script-vm/cutscene-scheduler.md`.
