Master sound effect translation table mapping high-level script and event sound indices (used by opcode `0x30` and animation script `sound` commands) to internal APU sound driver IDs.
Contains 112 16-bit word values (224 bytes total, `$8C:8362`..`$8C:8441`). An entry of `$FFFF` designates an unmapped or silent trigger.

Read during audio dispatch to configure parameter register `$7E:0E4F` before triggering SPC700 handshake via `$8C:82DC`.
