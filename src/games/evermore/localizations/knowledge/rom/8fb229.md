# combat_hitbox_bounds_overlap_test

Tests 2D Axis-Aligned Bounding Box (AABB) intersection between attack hitbox and target hurtbox.

## Metadata
- **Address:** `$8F:B229`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 100 bytes

## Functionality
Narrowphase collision primitive for melee attacks and weapon contact.
The routine compares attacker attack hitbox bounds against target entity hurtbox coordinates.

It evaluates left/right horizontal overlap and top/bottom vertical overlap; if both dimensions intersect, it returns Carry Set to signal a confirmed hit; otherwise, it exits with Carry Clear.
