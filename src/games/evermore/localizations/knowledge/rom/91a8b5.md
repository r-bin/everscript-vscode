# spell_projectile_screen_anchor_and_oam_dispatch

Updates spell projectile animation frame sequence, calculates elevation, and dispatches to OAM draw.

## Metadata
- **Address:** `$91:A8B5`
- **Type:** `routine`
- **Bank:** `$91`
- **Size:** 111 bytes

## Functionality
Advances the visual animation and spatial screen projection of active spell projectiles.
The routine steps the projectile animation frame cel via `$90:80D2`. It checks screen-anchor mode flags (`$91:0002,X`); for anchored projectiles, it centers coordinates at screen midpoint (`#$80` / `#$70`), whereas for world projectiles it computes screen space position and vertical elevation offsets via `$8F:C824`, then dispatches to `$91:A924` (`spell_projectile_oam_sprite_render`).

## Callers
- Direct spell particle physics dispatch in Bank `$91`

## Callees
- `$8F:C824` (`spell_screen_projection_with_elevation`)
- `$90:80D2` (`func_9080D2`)
- `$91:A924` (`spell_projectile_oam_sprite_render`)

## Variables and Memory
- `$0106` (Active screen graphics transition mode)
- `$15CC` (Projectile animation lifetime frame counter)
- `$1594`, `$1596` (Screen anchor coordinate words)
