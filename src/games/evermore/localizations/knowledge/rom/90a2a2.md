Searches and activates background tile animation channels:
- Scans descriptor slot table `$7E:507D`..`$7E:509D` looking up property keys in room blob `[$A7]`.
- Matches channel key against DP `$06`.
- Initializes channel state: sets frame index `$7E:4FE6,X = 0`, delay timer `$7E:5018,X` from descriptor byte, and loop repeat count `$7E:504A,X` (`0xFF` for infinite looping).
