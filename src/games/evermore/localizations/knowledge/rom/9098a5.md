Calculates per-frame horizontal and vertical camera jitter displacements during active screen shakes.
Uses the SNES 8-bit hardware multiplier (`$4202`/`$4203` `WRMPYA`/`WRMPYB` and `$4216` `RDMPYH`) to scale RNG rolls and frame counter ticks across the $[-magnitude, +magnitude]$ pixel bounds, outputting signed offsets to DP `$C5` (X offset) and DP `$C7` (Y offset).

## Addresses
- Screen shake active flag: DP `$C3`
- Jitter offset X: DP `$C5`
- Jitter offset Y: DP `$C7`
- Horizontal magnitude: `$7E:2409`
- Vertical magnitude: `$7E:240B`
- Frame seed: `$7E:0134`
- Hardware Multiplier Registers: `$4202`, `$4203`, `$4216`
