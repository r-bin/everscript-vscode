# camera_viewport_bounds_clamp_and_seam_check

Centers camera viewport on target coordinates, clamps within room boundaries, and triggers tile streaming.

## Metadata
- **Address:** `$90:94CD`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 120 bytes

## Functionality
Maintains room camera framing during player locomotion and scrolling cutscenes.
The routine offsets target coordinate `X` by screen half-width (`#$80`), clamping the result against room minimum (`$7E:23E9`) and maximum (`$7E:23ED`) world bounds.

It writes validated camera coordinates to `$59` and `$BF`, and calls `$90:93AA` to test and queue VRAM tilemap boundary seams.

## Variables and Memory
- `$59`, `$BF` (Active camera horizontal world position)
- `$7E:23E9` (Room minimum horizontal scrolling boundary)
- `$7E:23ED` (Room maximum horizontal scrolling boundary)
- `$0F3A` (Camera frame movement counter)
