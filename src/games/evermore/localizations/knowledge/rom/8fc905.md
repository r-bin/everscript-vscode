# entity_animation_sprite_direction_and_offset_init

Initializes entity directional animation offsets and frame strides from facing angle words.

## Metadata
- **Address:** `$8F:C905`
- **Type:** `routine`
- **Bank:** `$8F`
- **Size:** 253 bytes

## Functionality
Computes facing direction strides and base frame pointers for animated entities.
The routine extracts facing direction bits from entity attribute `$02,X` and indexes direction tables.

It configures animation descriptor offsets at `$07,Y`, initializes step counters at `$06,Y` and `$0A,Y`, and configures hardware Direct Page register to base `$2100` for rapid PPU register operations.

## Callers
- `$90:887B` (`func_90887B`)

## Callees
- None

## Variables and Memory
- `$02,X` (Entity facing angle / direction parameter)
- `$04,Y` (Facing direction mode index)
- `$07,Y` (Directional animation frame offset)
