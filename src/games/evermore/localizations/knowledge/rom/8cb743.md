# video_subsystem_hardware_registers_and_ppu_reset

Resets SNES PPU registers, forced blanking, window masks, and VRAM DMA transfer queues during scene transitions.

## Metadata
- **Address:** `$8C:B743`
- **Type:** `routine`
- **Bank:** `$8C`
- **Size:** 214 bytes

## Functionality
Reinitializes video and PPU hardware subsystems during map loads and screen transitions.
The routine invokes `$8C:C4F6` and `$80:8507` to flush pending DMA queues and silence sound channels.

It configures forced blanking via PPU register `$2100` (`#$8F`), initializes sprite sizes via `$2101` (`#$03`), and clears window mask registers `$010E..$0118` to prepare clean display buffers for incoming scene graphics.

## Variables and Memory
- `$2100` (SNES PPU Screen Display register - forced blanking)
- `$2101` (SNES PPU Object Size and OAM base register)
- `$010E..$0118` (Window clipping and masking configuration words)
