Vectors always point into bank `$00`, so the NMI enters at `$00:823A`. That address holds only a
4-byte `JML $80:823E` into the FastROM copy, where the handler body runs: VRAM/CGRAM queue uploads,
PPU register copies and `INC $0100`, all described in the WRAM entries that link here.

Why it matters for layout ports: under ExHiROM, `$00:8000+` is a different part of the ROM (file
`0x408000+`), and under SA-1 it is LoROM-style. So the port has to put the vector table and this stub
there; the handler itself stays where it is. The ExHiROM build copies the stub to file `0x40823A`.

## Notes
Previously believed: "the first 17 bytes of the NMI handler run through bank `$00`". The 17 bytes are
really 13 bytes of the reset entry and the 4-byte NMI `JML`.
