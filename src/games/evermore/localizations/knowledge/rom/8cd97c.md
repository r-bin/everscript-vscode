Clears one text-window record and resumes the queued cutscene dialogue stream. The `u8` operand selects a window; `$8C:D967` converts it to the record address `$034D + operand * $2C`. The handler clears that record through `$8C:ADE5`, then calls `$8C:C55D` to activate the next queued dialogue script. It returns Carry Set, so the opcode itself does not yield.

Operands: `u8` (text-window index; tokens: docs/game-research/script-vm/README.md). Flow: continues in the same turn.
