Evaluates an entity followed by two expressions, shifts each expression left four bits, and adds the results to that entity's `+$1A`/`+$1C` coordinates in DP `$46`/`$48`. It selects the shared continuation's skip mode, so `$8F:AA82` is not called and the opcode path does not write the entity coordinates. The purpose of these scratch-only values remains unresolved. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$1A`, `+$1C`, `+$2A`
- Opcode table entry: `$8C:E99B` (0x6f)
