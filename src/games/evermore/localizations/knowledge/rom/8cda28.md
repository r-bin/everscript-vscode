Entity, dx, dy expressions; each offset * 16 is added to the entity's `+$1A`/`+$1C`, then the shared path `$8C:DAA6` queues a walk through `$8F:AAD3`: no elevation lookup, layer `$44` = 0, move record flags `$0230`. A dead entity other than Boy/Dog is skipped. Returns Carry Set.

Previously believed: the coordinates were only staged and nothing moved; the mode flag selects `$8F:AAD3` instead of `$8F:AA82`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AA82`; `$8F:AAD3`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$1A`, `+$1C`, `+$2A`
- Opcode table entry: `$8C:E99B` (0x6f)
