Master environmental weather preset database located in ROM Bank `$EC`.
Holds 128-byte (64 16-bit words) configuration blocks for ambient precipitation modes:
- `+0x00`: Horizontal particle velocity baseline ($v_x$)
- `+0x02`: Vertical fall velocity baseline ($v_y$)
- `+0x04`: Wind turbulence sway amplitude
- `+0x06`: Oscillation frequency
- `+0x08`..`+0x0E`: Particle spawn bounding box ($x_{min}, x_{max}, y_{min}, y_{max}$)
- `+0x10`..`+0x3E`: Particle sprite OAM attributes and palette tags
- `+0x40`..`+0x7E`: Lifecycle frames, splash animations, and recycling states

Copied into active simulation memory `$7E:72D1`..`$7E:734F` by `load_weather_preset_parameters` (`$80:A2E0`).
