Updates an entity's complete 3D world position (X, Y, Z) and refreshes map tile collision:
1. Writes Z (`+$18`), X (`+$1A`), and Y (`+$1C`).
2. Calculates tile coordinates `tile_x = x >> 4` and `tile_y = y >> 4`.
3. Verifies coordinates are within room dimensions (`$7E:08EE` width, `$7E:08EF` height).
4. Employs SNES hardware multiplier registers `$004202` / `$004216` to compute linear tile index: `(tile_y * map_width + tile_x) * 2`.
5. Stores linear tile byte offset at `entity->tile_offset` (`+$3A`).
6. Looks up tile collision word from `$7F:0000 + offset` and terrain surface flags from `$7F:0004 + collision_word`, storing in `entity->surface_flags` (`+$3C`).
7. Updates attached child entities via `$8F:A7D3`:
   - Shadow entity (`+$6A`)
   - Carried/held entity (`+$6C`)
   - Auxiliary attachment (`+$98`, status bubble / barrier effect on player/companion)

## Addresses
- Map Width (tiles): `$7E:08EE`
- Map Height (tiles): `$7E:08EF`
- Hardware Multiplier Registers: `$00:4202` / `$00:4216`
- Tile Map Buffer: `$7F:0000`
- Tile Attribute Table: `$7F:0004`
- Child Entity Reposition Routine: `$8F:A7D3`
- Script Opcode 0x43 Caller: `$8C:E00D`
