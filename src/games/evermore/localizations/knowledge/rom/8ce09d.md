Handler of script opcode [0x7B](soe://rom/assets/scripts/opcodes/7b.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/7b.md`, served at `soe://rom/assets/scripts/opcodes/7b.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$00`
- Opcode table entry: `$8C:E9B3` (0x7b)
