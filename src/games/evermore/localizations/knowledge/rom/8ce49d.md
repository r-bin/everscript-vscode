Evaluates horizontal and vertical screen-offset expressions and passes them to `$90:A001`. The helper shifts the camera by 512 pixels per screen and attempts to move each active entity by the same offset, skipping an entity's position update when the destination is impassable.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$90:A001` Teleport camera and active entities by (dx, dy) screens
- Opcode table entry: `$8C:E9E9` (0x96)
