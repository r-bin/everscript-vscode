# mode7_sky_color_gradient_and_fade_cgram_dma

Calculates dynamic sky horizon color gradients and schedules CGRAM backdrop palette DMA updates.

## Metadata
- **Address:** `$80:D7B0`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 250 bytes

## Functionality
Computes the dynamic sky backdrop color during Mode 7 flight sequences.
The routine queries environmental time and altitude tint parameters in `$0100`, computes sky color gradients in `$0E7E`, and queues palette DMA transfers to CGRAM color 0 via `$80:85FA` (`cgram_palette_dma_enqueue_or_immediate`).

## Callers
- `$80:C1A2` (`FUN_80c1a2`)
- `$80:C95B` (`FUN_80c95b`)

## Callees
- `$80:85FA` (`cgram_palette_dma_enqueue_or_immediate`)

## Variables and Memory
- `$0100` (Sky environment and time of day lighting value)
- `$0E7E` (Computed 15-bit RGB sky backdrop color word)
- `$26`, `$28` (Pointer to sky palette color buffer in WRAM)
