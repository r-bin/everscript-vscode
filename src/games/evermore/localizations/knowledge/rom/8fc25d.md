Processes pending damage for an entity and dispatches hit reaction behavior:
1. Transfers queued damage from `entity->pending_damage` (`+$76`) into `entity->last_damage_taken` (`+$AA`).
2. If `entity->hud_bar_active` (`+$8E`) is set, updates the onscreen HUD health bar string via `$8F:9144`.
3. Clears `pending_damage` (`+$76 = 0`).
4. Checks remaining HP (`+$2A`): if 0, immediately triggers the death/recoil animation at `$8F:C290`.
5. Checks combat flinch eligibility (`+$16` Bit 0) and boss stagger overrides (`$7E:0EB8` Bit 5) before triggering recoil.

## Addresses
- Pending Damage Field: `+$76`
- Last Damage Taken Field: `+$AA`
- HUD Bar Active Flag: `+$8E`
- Current HP Field: `+$2A`
- HUD Text Formatter: `$8F:9144`
- Damage Reaction Trigger: `$8F:C290`
