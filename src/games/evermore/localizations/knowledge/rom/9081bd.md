Renders an animation record’s active frame graphic directly into the OAM staging buffer. Reads 24-bit frame pattern pointer from `+$06,X` / `+$08,X`, sets direct page graphics source `$26..$28`, masks palette bits `+$0C,X` into attribute word `$06`, and commits the sprite to OAM via `$80:9033`.
