Expression to `$05A7`, then the shop menu `$8E:9FA8` for the item kinds collected in `$0E6C` by opcode `0x89`. The original scripts never use it.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8E:9FA8`
- Reads WRAM: `$7E:0E6C`
- Writes WRAM: `$7E:05A7`
- Reads ROM: `$8C:E37B`
- Opcode table entry: `$8C:E9D1` (0x8a)
