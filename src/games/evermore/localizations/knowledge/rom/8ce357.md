Evaluates `E` into `$05A7`, selects a dispatch value from `$8C:E37B` using the mode bits at `$0E6C`, and places the selected value in DP `$97` when nonzero. With the required mode bit set, calls `$8E:9FA8` to route shop-catalog behavior. Returns Carry Set; the meaning of `$05A7` is not established here.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8E:9FA8`
- Reads WRAM: `$7E:0E6C`
- Writes WRAM: `$7E:05A7`
- Reads ROM: `$8C:E37B`
- Opcode table entry: `$8C:E9D1` (0x8a)
