Evaluates an amount-table offset followed by a value. Adds the value to the low word at `$0AC6,X`, then propagates carry into the high byte at `$0AC8,X`; X is the first expression's result. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Reads WRAM: `$7E:0AC6`; `$7E:0AC8`
- Writes WRAM: `$7E:0AC6`; `$7E:0AC8`
- Opcode table entry: `$8C:E9C5` (0x84)
