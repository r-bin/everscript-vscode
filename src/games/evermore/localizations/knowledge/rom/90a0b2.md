# room_canopy_terrain_tilemap_row_stride_index

Calculates 32-tile row stride offsets for room canopy and terrain tilemap decompression.

## Metadata
- **Address:** `$90:A0B2`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 143 bytes

## Functionality
Assists in mapping compressed room tile blocks to target VRAM and WRAM tilemap memory layouts.
The routine takes vertical coordinate offset in `$2E`, applies bitwise shifts to compute 32-tile row strides, stores the calculated stride in `$106E`, and invokes `$90:934B` to prepare decompression target pointers.

## Callers
- `$90:91B0` (`Block_3_canopy_terrain_collision_words_to_90_9245_9091B0`)

## Callees
- `$90:934B` (`FUN_90934b`)

## Variables and Memory
- `$2E` (Vertical room tile coordinate offset)
- `$106E` (Calculated tilemap buffer row stride)
- `$26`, `$28` (Staging buffer pointer words)
