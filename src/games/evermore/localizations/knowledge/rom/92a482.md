Called by gourd/chest B-triggers after they stage the loot mailbox (`$2391` item, `$2395`
object, `$2461` amount−1). If the **boy** is not the controlled character it only clears
`$22EA` bit 0 (loot successful) — the dog's fake pickup. Otherwise: stop the boy, set the
object's state to `0x63`, call global `0x3e` (count it in), then `0x3f` (success text) when
`$22EA` bit 0 is set or `0x41` (bag full) when not, reset the object, give control back,
and write `$2461 = 0`.

Siblings: global `0x39` at `$92:A44C` (sniff spot: same, plus the dog's dig animation) and
global `0x3b` at `$92:A4B3` (a second gourd variant, used e.g. by `$94:AD6E`).

A gourd's room object has two appearances (`maxState` 1): state 0 closed, state 1 open. The
Routes tab draws a taken gourd in state 1; which script sets that state on a later visit (the
enter script testing the taken flag) is not traced yet.
