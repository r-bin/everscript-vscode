Name pointers into bank `$C4`: the first 23 are the spell names by cast id (`$C4:5F97` holds their
blocks), the next 22 (from `$C4:5FF3`) the alchemy ingredients, Wax … Acorn. A cast id past `$2C`
reads an ingredient name — which is why the compiler's old `CAST.WATER = $30` exists: it is not a
spell.
