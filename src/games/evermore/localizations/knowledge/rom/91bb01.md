Synchronizes sprite graphics and palette assignments for party members (Boy `$0F3E` or Dog `$0F40`). If entity record `Y` matches a player character and override flag `$91:AE35,X` is set, updates sprite frame graphics via `$90:C9B2` and reloads character sprite palette into CGRAM via `entity_apply_palette_slot` (`$90:CDDC`).
