Halts active screen tremor by zeroing the shake active flag (DP `$C3`), horizontal jitter offset (DP `$C5`), vertical jitter offset (DP `$C7`), and countdown timer (DP `$C9`).
Called directly by script opcode `0x8D` (`$8C:E385`) when operand is 0.

## Addresses
- Screen shake active flag: DP `$C3`
- Jitter offset X: DP `$C5`
- Jitter offset Y: DP `$C7`
- Shake timer: DP `$C9`
- Caller: `$8C:E385`
