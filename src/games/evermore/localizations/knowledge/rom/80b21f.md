Converts an unsigned 32-bit (or 24-bit currency/experience) integer stored in Direct Page registers `$02` (low word) and `$04` (high word) into an ASCII decimal digit character string written to destination far pointer `[$22]`:
- Tests if input value is zero (`LDA $02; ORA $04`). If zero, directly writes single ASCII digit `'0'` (`$0030`), sets string length `Y = 1`, advances destination write cursor `X = $22 + 1`, and returns via `RTL`.
- For non-zero values, invokes division subroutine `$80:B283` to extract BCD digits, suppresses leading zeroes, converts each digit byte to ASCII (`digit + 0x30`), stores the resulting character sequence into destination buffer `[$22]`, updates pointer `X`, and returns the total formatted string length in `Y`.
- Extensively used by shop purchase confirmations, inventory gold balance displays, experience point reports, dialogue variables (`TEXT_MEM1`..`TEXT_MEM3`), and target actor combat stat cards.
