Evaluates an entity expression, decrements its reference count at `+$3E`, then calls `$8F:B2DE`. The helper releases attached resources, restores entity motion, clears HP at `+$2A`, and performs disposal when the reference count is zero. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:B2DE`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$3E`
- Opcode table entry: `$8C:E9F3` (0x9b)
