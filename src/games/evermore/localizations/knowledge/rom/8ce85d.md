Maps the first expression through `$8C:E899` to a descriptor slot, then evaluates three more expressions to form the starting index, span, and descriptor flags passed to `$90:D50F`. That helper reserves the extra graphics range in descriptor tables. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:E899`; `$90:D50F` Reserve the CHR descriptors' extra graphics
- Opcode table entry: `$8C:EA29` (0xb6)
