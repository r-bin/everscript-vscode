Palette (8-15), first colour, last colour and speed expressions. `$8C:E899` loads the palette (from `$90:A7CB` + the variant offset `$23CB`, `$90:CF3A`), then `$90:D50F` starts rotating its colours first..last; the sign of the speed is the direction. Everscript `tile_flashing`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:E899`; `$90:D50F` Reserve the CHR descriptors' extra graphics
- Opcode table entry: `$8C:EA29` (0xb6)
