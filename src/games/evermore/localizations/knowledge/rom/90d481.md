# map_palette_change_and_cgram_reload_enqueue

Enqueues dynamic CGRAM palette reloads when an event script modifies map lighting.

## Metadata
- **Address:** `$90:D481`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 133 bytes

## Functionality
Triggered when an Everscript command alters map palette definitions (such as day/night transitions or dungeon lighting shifts).
The routine checks palette update trigger flag `$150C`. If pending, it copies new palette definitions from source tables (`$D441`, `$7E:65D1`) using `$90:D34C` (`memory_block_copy_indirect_words`) and schedules CGRAM DMA updates via `$80:85FA`.

## Callers
- `$90:CBB3` (`Reload_families_when_a_script_changes_MAP_PALETTE_90CBB3`)

## Callees
- `$80:85FA` (`FUN_8085fa`)
- `$90:D34C` (`memory_block_copy_indirect_words`)

## Variables and Memory
- `$150C` (Scripted map palette reload request flag)
- `$7E:65D1` (Dynamic ambient lighting palette buffer in WRAM)
