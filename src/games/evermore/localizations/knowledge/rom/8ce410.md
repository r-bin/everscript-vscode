Evaluates an entity expression and an amount expression, then calls `$8F:C09A`. That helper restores HP, applies a palette flash, updates the player HUD when applicable, and clears pending damage and selected state bits. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:C09A`
- Opcode table entry: `$8C:E9E5` (0x94)
