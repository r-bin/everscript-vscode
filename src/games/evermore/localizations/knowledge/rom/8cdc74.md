Starts a music fade-out: the volume step `$9B` = `$F0` (-16), then `$8C:8619` adds the step to the music volume `$9A` and sends it with sound driver command `$28` (volume, the same command as opcode `0x86`); at 0 the step is cleared.

Previously believed: a screen palette fade.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$8C:8619`
- Opcode table entry: `$8C:E96F` (0x59)
