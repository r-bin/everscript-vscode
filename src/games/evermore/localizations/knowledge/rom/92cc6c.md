Timer division routine for the Nobilia Market 15-minute countdown clock.
Computes elapsed real time by subtracting the session start timestamp `MARKET_TIMER_START_FRAME` (`$7E:2513`) from the hardware frame counter `frame_counter_low()`. Walks a ladder of 3,600-frame steps (60 fps * 60 sec = 1 minute) to write the remaining minutes value (15 down to 1) into `MARKET_TIMER_MINUTES_REMAINING` (`$7E:2515`).
