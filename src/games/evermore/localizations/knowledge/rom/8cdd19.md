Common tail routine for all entity and character spawn script VM opcodes:
- Evaluates target tile plane elevation via `$8F:A933`.
- Tests bit 15 (`0x8000`) of argument 2 in `DP $08`:
  - If bit 15 is set: branches to `$8C:DD2D` to invoke `$8F:DE98` (`spawn_stage_deferred_entity`).
  - If bit 15 is clear: calls `$8F:B094` (`projectile_spawn_master`) and records the spawned entity pointer to `$7E:0341`.
- Sets carry (`SEC`) and returns (`RTS`).
