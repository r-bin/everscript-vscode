# particle_emitter_timeline_step_and_palette_lerp

Steps particle emission scripts and interpolates color palette fading via hardware color lerp.

## Metadata
- **Address:** `$90:D7DD`
- **Type:** `routine`
- **Bank:** `$90`
- **Size:** 123 bytes

## Functionality
Drives timed particle effects such as spell auras, alchemical explosions, and teleport sparkles.
The routine advances timeline pointer `$ECA,Y`, checks remaining frame durations in `$EC8,Y`, and dispatches step behaviors via indirect jump `JSR ($00,X)`.

It invokes `$90:D2A6` (`graphics_color_555_linear_blend_lerp`) and `$80:85FA` to execute color palette fades as particles age and disperse.

- `$EC8,Y` (Current timeline keyframe duration counter)
