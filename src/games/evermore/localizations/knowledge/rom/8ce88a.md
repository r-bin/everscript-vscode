Handler of script opcode [0xB7](soe://rom/assets/scripts/opcodes/b7.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/b7.md`, served at `soe://rom/assets/scripts/opcodes/b7.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:E899`
- Writes WRAM: `$7E:13D2`
- Opcode table entry: `$8C:EA2B` (0xb7)

The raw-expression index used by B7 after the palette loader call is documented in [opcode-b7-palette-cycle-stop.md](../../../../../../docs/disassembly/script-vm/opcode-b7-palette-cycle-stop.md) and modeled in `reconstructed-c/8C/8CE88A_opcode_b7_palette_cycle_stop.c`.
