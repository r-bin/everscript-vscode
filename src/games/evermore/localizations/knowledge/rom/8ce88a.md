Maps its expression through `$8C:E899` to a descriptor slot and clears the word at `$7E:13D2,X`. This releases the associated extra-graphics reservation state. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:E899`
- Writes WRAM: `$7E:13D2`
- Opcode table entry: `$8C:EA2B` (0xb7)
