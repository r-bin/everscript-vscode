Bank `$91` ASM routine that inspects bit 1 of entity slot offset `+0x26`. This bit is set by opcode
`0x5D` (`effect_done`) when an alchemy animation phase finishes in the Bank `$90` Animation Script VM.
This signals the Bank `$91` ASM coordinator to resolve spell damage/effects (e.g. at `$91:9C90`) and
advance the active effect slot to the next animation phase (e.g. Part A to Part B).
