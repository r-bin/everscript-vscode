Inspects bit 1 of entity slot offset `+0x26` to determine if an alchemy animation
phase has completed (signaled by animation script opcode `0x5D`).
Clears the bit and returns Carry Clear (`CLC`) to trigger spell damage calculation
or Carry Set (`SEC`) to yield.
Full disassembly and clean C reconstruction: `docs/disassembly/combat/spell-targeting.md`.
