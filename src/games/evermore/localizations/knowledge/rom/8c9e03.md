Coordinates dialogue string line formatting, token expansion, and proportional word-wrapping
for in-game text windows. Scans string bytes: control tokens `0x81`–`0x84` expand dynamically
into Boy's name (`$7E:2210`), Dog's name (`$7E:2234`), `"player 3\0"`, and `"player 4\0"`.
Accumulates character widths from font metrics table at `[$92]` and wraps lines before overflowing
window column bounds (`$0E,Y`).
