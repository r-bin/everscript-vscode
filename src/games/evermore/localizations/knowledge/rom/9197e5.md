Target proximity / collision detection check for alchemy particle slots. Reads target entity position `(+$1A,X, +$1C,X)` and calculates horizontal delta relative to particle `+$48,Y` and vertical delta relative to `+$4A,Y` (adjusting for sprite elevation `+$1E,X`). Returns `SEC` if within collision box ($|\Delta X| < 16$ and $|\Delta Y| < 32$), else `CLC`.
