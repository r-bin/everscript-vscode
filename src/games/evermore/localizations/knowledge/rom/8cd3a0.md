Handler of script opcode [0xA3](soe://rom/assets/scripts/opcodes/a3.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/a3.md`, served at `soe://rom/assets/scripts/opcodes/a3.md`.

Previously believed: id*3 into the trigger table — that lands in sniff-spot scripts, not in
the globals. `Machine.globalScript()` implements the formula.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$8C:CF18` Script VM — allocate a slot for a script
- Writes WRAM: `$7E:2F28` Script run list — slots in run order, zero-terminated
- Reads ROM: `$92:8000` Script bank header; `$92:8002` in Script bank header (+$2); `$92:8008` in Script bank header (+$8)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$0B`, `+$0D`, `+$3E`
- Opcode table entry: `$8C:EA03` (0xa3)
