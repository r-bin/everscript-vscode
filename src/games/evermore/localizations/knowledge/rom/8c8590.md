Calculates 2D screen-space distance attenuation and left/right stereo panning for positional sound effects
emitted by entities in the room. Uses precomputed squared table `$80:AA27` and square root function `$80:AC27`
to evaluate Euclidean distance from screen center, maps distance to volume falloff via table `$8C:84D4`,
and transmits stereo panning commands (`0x0036`) to the SPC700 coprocessor via `$8C:81FD`.
Full disassembly and clean C reconstruction: `docs/disassembly/audio/sfx-arbitration.md`.
