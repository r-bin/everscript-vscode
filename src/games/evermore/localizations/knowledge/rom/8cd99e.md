Handler of script opcode [0x52](soe://rom/assets/scripts/opcodes/52.md). If `$7E:23D3` is zero and bit 15 of `$7E:0B2B` is clear, resets the subtitle queue/window, then resolves a 16-bit string key through `$8C:CD33` and enqueues the resulting far pointer through `$8C:C521`. It returns carry set. The host-side model is documented in `docs/disassembly/script-vm/opcode-52-subtext.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$8C:C4F6`; `$8C:C521`; `$8C:CD33`
- Reads WRAM: `$7E:0B2B`; `$7E:23D3` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$1D3)
- Opcode table entry: `$8C:E961` (0x52)
