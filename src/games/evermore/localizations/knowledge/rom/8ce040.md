Evaluates an entity and raw X/Y offsets. Zero offsets, entity status bit `$0008`, or a failed `$8F:AF48` movement/collision probe prevent the coordinate update; on a successful probe it calls `$8F:C2E4` to set the entity's world coordinates. The handler writes `$0001` to `$23E3` on its early-out paths. Returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8F:AF48`; `$8F:C2E4`
- Writes WRAM: `$7E:23E3` in Persistent RAM across rooms (names, story flags, markets, alchemy) (+$1E3)
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$10`, `+$1A`, `+$1C`
- Opcode table entry: `$8C:EA2F` (0xb9)
