Adds awarded enemy combat experience into the active character's 24-bit accumulator (`$7E:0AC6,x` and
`$7E:0AC8,x`). If a level milestone threshold is reached, it triggers the level-up fanfare via `$80:B37A`,
loads string pointer `$8F:86FA` to display the floating "LEVEL UP!" banner via `$80:B149`, and updates
the player's HUD gauges.
Full disassembly and clean C reconstruction: `docs/disassembly/combat/exp-level-up.md`.
