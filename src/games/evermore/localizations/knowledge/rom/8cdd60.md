Expression = an entity, or a small index n (< `$2000`). Entity: the first word is its event mask (`+$68`), the second the event script's trigger id (`+$66`). Mask bits: `$0040` run on talk, `$0100` when hit, `$0200` on death (one-shot), `$0400` run now: `$8C:CE4D` starts the script as a thread at once. Index n: the two words go to room hooks `$0EA2 + 2(n-1)` / `$0EAC + 2(n-1)`; when the first is 0 the second becomes `$FFFF`. Both words are always consumed.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Calls: `$8C:CE4D`
- Writes WRAM: `$7E:0EA2`; `$7E:0EAC`
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$66`, `+$68`
- Opcode table entry: `$8C:E93B` (0x3f)
