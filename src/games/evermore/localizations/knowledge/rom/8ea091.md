Called during cold boot and room transitions (`enter_room` `$8E:E4E2`) to instantiate persistent character script threads:
- Passes character entity pointer (`$4E89` for Boy, `$4F37` for Dog).
- Allocates an execution thread slot in the script VM dispatcher (`$8C:CFFD`).
- Schedules the script for round-robin execution.
