Standard consumable projectile hit resolution proc (index 2 in table `$8F:B6AE`).
Used by arrows, thrown spears, mud balls, and monster projectiles.

Evaluates projectile to-hit and invulnerability via `$8F:B9F8`.
Calculates scaled damage from power parameter `$7E:0E9C` via `$8F:C06D`, applies damage via `$8F:C0D3`, and triggers knockback via `$8F:C17F`.
Deletes the projectile entity by clearing status word `$0010,x` for entity pointer in `$7E:0E9E`.
Checks if the hit dealt a fatal blow (`damage >= victim->hp`), awarding weapon skill XP to Boy (`$8F:973E`) or combat XP to Dog (`$8F:97C0`).
Returns Carry Clear (`CLC`) to terminate the strike scan upon impact.
