Fades the screen out to black (`0x00`). Writes `$8000` (fade active, target brightness 0) to
the screen fade controller `$7E:0B83`. The engine's per-frame loop (`$80:DE95`) steps `$7E:0106`
(`INIDISP` shadow) down towards 0 until black is reached, then zeroes `$7E:0B83`.

Operands: none (tokens: docs/game-research/script-vm/README.md). Flow: continues in the same turn.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Writes WRAM: `$7E:0B83` Screen brightness fade controller
- Opcode table entry: `$8C:E90B` (0x27)

## Notes
Previously believed: hypothesized in earlier notes to be a joypad control lock. Routine `$80:DE95`
confirms that `$7E:0B83` with bit 15 set drives stepped fading towards the low-byte target brightness (here 0).
