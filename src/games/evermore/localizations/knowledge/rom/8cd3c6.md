Handler of script opcode [0xAF](soe://rom/assets/scripts/opcodes/af.md). What it does, why it exists and how scripts use it: the opcode entry `knowledge/opcodes/af.md`, served at `soe://rom/assets/scripts/opcodes/af.md`.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Calls: `$8C:CF18` Script VM — allocate a slot for a script; `$8C:D315` Script VM — read call arguments
- Writes WRAM: `$7E:2F28` Script run list — slots in run order, zero-terminated
- Record fields (indexed by X/Y: a slot, an entity, a window): `+$0B`, `+$0D`, `+$3E`
- Opcode table entry: `$8C:EA1B` (0xaf)

The argument and far-target decoding is documented in [opcode-af-call-with-args.md](../../../../../../docs/disassembly/script-vm/opcode-af-call-with-args.md) and modeled in `reconstructed-c/8C/8CD331_callback_dispatch.c`.
