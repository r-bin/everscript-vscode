Retrieves or allocates a secondary child attachment entity for a parent (such as an auxiliary boss part or projectile launcher).
Checks `parent->secondary_child` (`entity + 0x6C`). If absent, pops from the child free list at `$7E:3BC7` (or scans to transfer a primary attachment if exhausted), registers cross-references, calls waypoint anchor init `$8F:9937`, and returns with Carry Set (`SEC`).
