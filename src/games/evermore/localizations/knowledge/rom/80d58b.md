# mode7_flight_hud_indicator_oam_formatter

Formats Mode 7 flight telemetry indicator sprites and compass direction markers into OAM buffers.

## Metadata
- **Address:** `$80:D58B`
- **Type:** `routine`
- **Bank:** `$80`
- **Size:** 472 bytes

## Functionality
Generates HUD indicator sprites displayed over the Mode 7 world map during Windwalker and flight gameplay.
The routine reads aircraft heading `$14C6`, queries orientation sprite tables at `$80:EAA2`, and formats sprite attributes (tile number, palette, coordinate offsets) into the OAM buffer at `$ACC0` for presentation above the Mode 7 landscape.

## Callers
- `$80:D22D` (`func_80D22D`)

## Callees
- None

## Variables and Memory
- `$14C6` (Mode 7 aircraft yaw heading angle)
- `$80:EAA2` (ROM flight indicator orientation table)
- `$ACC0` (OAM buffer target for telemetry overlay sprites)
