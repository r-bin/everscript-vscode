Multiplies an 8-bit input by each byte of the 16-bit value in DP $06 using the SNES hardware
multiplier. Let `p_lo = multiplier * (DP06 & 0x00FF)` and
`p_hi = multiplier * (DP06 >> 8)`. On return, DP `$02 = p_lo`,
DP `$03 = ((p_hi & 0xFF00) | (p_lo >> 8))`, and DP `$04 = p_hi >> 8`.
The carry branch after adding `p_lo` to cleared DP `$02` is unreachable for these 8-by-8
products. The host C implementation is in `reconstructed-c/90/909D45_heat_shimmer.c`.
