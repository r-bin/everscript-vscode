Evaluates an index expression, then reads a 16-bit low part and an 8-bit high part. It subtracts that 24-bit immediate from the three-byte amount at `$0AC6,X` (low word) and `$0AC8,X` (high byte), propagating borrow, then returns Carry Set.

## Addresses
Read from the handler's code (direct calls only; data bank tracked, default `$7E`):
- Operand expressions: `$8C:EA43` (`$8C:EC8E` for an entity: the result also goes to DP `$4C`)
- Reads WRAM: `$7E:0AC6`; `$7E:0AC8`
- Writes WRAM: `$7E:0AC6`; `$7E:0AC8`
- Opcode table entry: `$8C:E9B7` (0x7d)
