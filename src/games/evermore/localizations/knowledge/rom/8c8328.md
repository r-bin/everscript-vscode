Resolves the required sample package (BRR audio chunk) in SPC700 Audio RAM for a given music track
or sound effect:
- Queries master package catalog header at `$81:9900`.
- Computes base table offset: `$9903 + (([$81:9900] + 1) * 3)`.
- If `X == 0`, looks up track ID `$7E:0E44`.
- If `X != 0`, adds SFX section offset `$81:9901` and queries sound effect ID `$7E:0E4F`.
- Returns package ID in accumulator `A` for streaming via `$8C:8236`.
Full disassembly and clean C reconstruction: `docs/disassembly/audio/positional-audio.md`.
