CDL-identified pointer table in ROM at $91:8000.

The handler table of the alchemy effect VM: an op is a word, the even offset of its handler here (op `$00`
`$91:9B8B` … op `$A4` `$91:9D7A`). Known ops: `$02` spawns an animation record (the operand, e.g. `$583E`),
`$36` plays a sound, `$48` applies damage (`$91:9E66`), `$4A` branches (`$91:9DFA`), `$52` acquires the targets
(`$91:9C3E`). The table is followed by the block table, so a new op needs the table moved (one reader).
