Main per-frame rendering and physics pipeline coordinator for Mode 7 flight scenes:
1. **Window attributes**: Uploads window clip and plane attribute buffers via `vram_dma_upload_window_attribute_buffer` (`$80:D91B`).
2. **Pitch trajectory**: Scales transition counter `$14BA` to index horizon pitch lookup table `$80:F933`, writing the result into `MODE7_CAMERA_PITCH_OFFSET` (`$7E:14B4`).
3. **Yaw & Matrix**: Calculates trigonometric yaw rotation matrix via `mode7_flight_heading_yaw_rotation_matrix_calc` (`$80:D934`).
4. **Camera motion**: Coordinates rotated camera panning (`$80:DA9A`), screen-offset scroll (`$80:DCE1`), and screen shake damping (`$80:CE35`).
5. **HUD & Shadow**: Updates HUD compass needle tracking (`$80:DEC4`) and projects dynamic ground shadow geometry under the aircraft (`$80:D22D`).
6. **OAM commit**: Ticks sprite animation bytecode (`$90:80D2`), finalizes low/high OAM records (`$80:8FEE`), waits for NMI (`$80:858C`), and commits OAM tables via DMA (`$80:8F85`).
7. **Cockpit HUD overlay**: If cockpit HUD flag `$7E:246B` is set, calls `mode7_cockpit_heading_indicator_frame_tick` (`$80:C881`) and re-commits OAM.
